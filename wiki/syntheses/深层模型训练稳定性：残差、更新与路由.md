# 深层模型训练稳定性：残差、更新与路由

训练稳定性不是一个学习率参数能够概括的问题。现有资料分别从损失与梯度、跨层残差、矩阵更新、注意力幅度、MoE 路由和强化学习策略比率解释失稳。它们发生在不同层级，需要分别观测和约束。

## 从损失到参数更新

基础训练循环先计算预测与目标的 Loss，再由反向传播得到梯度，最后由 Optimizer 更新参数。Batch Size 与 Learning Rate 决定一次更新使用多少样本以及移动多远；`zero_grad()` 必须清除 PyTorch 默认累积的旧梯度。（[[wiki/sources/模型训练：梯度下降与均方误差|梯度下降]]、[[wiki/sources/模型训练：PyTorch 手写数字识别实战|PyTorch 训练实战]]）

LoRA 不改变这条基本链路，而是冻结原始权重，只训练低秩增量矩阵。它减少可训练参数、梯度和优化器状态，但不消除原始模型权重、激活或前向计算。（[[wiki/sources/大模型微调：LoRA 低秩适配|LoRA]]）

## 跨层信号：相加、选择与守恒

标准残差把前序表示直接相加，为梯度提供直通路径，也会让表示沿深度持续累积。Attention Residuals 改为对此前层表示动态加权；Full AttnRes 提供细粒度选择但保存全部层历史，Block AttnRes 用块级聚合降低成本。（[[wiki/sources/模型架构：Attention Residuals 层间选择性聚合|Attention Residuals]]）

DeepSeek V4 的 mHC 处理另一类多通道残差问题：通道混合矩阵若逐层轻微放大，深层组合后会放大前向信号与反向梯度。资料用双随机矩阵约束行列和，并通过迭代归一化把混合限制在对应空间中。AttnRes 解决“选哪些历史表示”，mHC 解决“多通道怎样混合而不持续增益”，两者不能互换。（[[wiki/sources/模型架构：DeepSeek V4 的长上下文与训练稳定性|DeepSeek V4]]）

## 矩阵更新：从逐元素缩放到正交化

AdamW 对梯度进行逐元素自适应缩放；Muon 将矩阵更新视为整体，通过 Newton–Schulz 迭代把不同方向的奇异值拉近。DeepSeek V4 资料中的 Hybrid Newton–Schulz 先快速收敛再精修，并让部分正交化与梯度同步使用 BF16；向量参数、Embedding 与 LM Head 仍由 AdamW 处理。（[[wiki/sources/模型架构：DeepSeek V4 的长上下文与训练稳定性|DeepSeek V4]]）

Kimi K2 Thinking 的 MuonClip 又增加 QK-Clip：它监控注意力 Logit，超过阈值时只缩放相关 Query／Key 投影，避免全局裁剪影响无关参数。MuonClip 与 DeepSeek V4 的组合都说明，优化器名称不足以描述稳定性，必须记录哪些参数走哪条更新路径以及触发条件。（[[wiki/sources/大语言模型：Kimi K2 Thinking 的 MoE 架构与 Agent 训练|Kimi K2 Thinking]]）

## MoE 路由：切断短时正反馈

MoE 中，异常 Token 可能把某个专家权重拉向自身，下一步路由又更偏向该专家，形成路由概率与专家参数之间的正反馈。DeepSeek V4 的 Anticipatory Routing 不是常态机制：资料明确描述为检测到 Loss Spike 后短暂回滚并临时启用，稳定后恢复标准训练。它使用较早的路由参数计算专家索引，同时保留当前门控权重与专家前向，以打断短时共振。（[[wiki/sources/模型架构：DeepSeek V4 的长上下文与训练稳定性|DeepSeek V4]]）

这类方案依赖模块间数值边界与系统实现。DeepGEMM、TileLang、3FS、DSec、DualPipe 等基础设施也属于资料所述复现条件，不能只复制公式便认定获得相同性能或稳定性。

## Agentic RL：稳定策略比率与信用分配

Agentic RL 的失稳发生在策略优化层。ARLArena 资料指出，容忍型 Token 级裁剪仍可能保留越界 Token 的梯度，使负优势序列持续腐蚀更新；SAMPO 改用序列级裁剪、步骤级优势和动态采样共同控制更新。（[[wiki/sources/大模型后训练：ARLArena 与 SAMPO 稳定 Agentic RL|ARLArena 与 SAMPO]]）

这与预训练中的残差、矩阵或路由失稳不是同一问题，但治理原则相通：先定位异常在哪个层级产生，再在共享路径上施加最小约束，不能用最终 Loss 曲线替代根因诊断。

## 最小观测集

训练稳定性至少需要分别记录：Loss 与梯度范数、残差通道幅度、矩阵奇异值或正交化误差、注意力 Logit、专家负载与路由集中度、策略重要性采样比率、序列和步骤级优势，以及回滚触发记录。某一指标稳定，不代表其他层没有失稳。
