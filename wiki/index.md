# AI 知识索引

本页是知识库的内容入口。当前收录 20 份资料摘要和 4 篇跨资料综合，内容沿 AI 应用从单轮指令到生产质量控制的主线组织。

## 知识主线

| 阶段 | 核心问题 | 综合入口 | 与下一阶段的关系 |
| --- | --- |
| Prompt | 当前任务怎样表达 | [[wiki/syntheses/提示词工程：从单轮指令到生产规范]] | 单条指令无法管理历史、知识与工具时，进入 Context |
| Context | 当前轮次让模型看到什么 | [[wiki/syntheses/上下文工程：有限窗口中的信息治理]] | 单轮信息治理需要跨轮持续触发和回写时，进入 Loop |
| Loop | 系统跨轮次怎样继续、验证与停止 | [[wiki/syntheses/循环工程：从逐轮操作到外部调度]] | 循环需要独立质量标准决定能否继续或上线时，进入 Evaluation |
| Evaluation | 怎样证明系统满足业务要求 | [[wiki/syntheses/评估工程：从通用基准到业务质量门]] | 评估结果回流到 Prompt、Context 和 Loop，形成改进闭环 |
