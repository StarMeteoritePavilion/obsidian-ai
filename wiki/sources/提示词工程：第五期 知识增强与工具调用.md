# 提示词工程：第五期 知识增强与工具调用

原始资料：[[raw/sources/应用工程/提示词工程/第五期：知识增强与工具调用|第五期：知识增强与工具调用]]

## 核心结论

大模型的知识与计算短板需要按类型补偿：生成知识提示显式唤起模型内部知识，编程语言推理把精确计算交给解释器，工具调用接入搜索、计算、翻译、日历等外部能力。

## 主要内容

- 生成知识提示先生成相关知识，再据此作答；生成的知识仍可能产生幻觉，需要多条采样和质量筛选。
- PAL 与 PoT 让模型负责把语义转换成计算步骤，让解释器负责精确执行。
- 执行模型生成的代码必须使用安全沙箱，不能把任意代码直接交给宿主环境。
- TALM、Toolformer 属于训练侧方案；生产系统也可以在不修改权重的情况下，通过提示与工具协议实现调用。
- 当任务同时需要推理、实时知识和外部行动时，可组合 CoT、任务拆分、工具链与记忆形成 Agent 工作流。
