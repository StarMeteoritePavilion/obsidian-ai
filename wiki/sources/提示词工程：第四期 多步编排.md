# 提示词工程：第四期 多步编排

原始资料：[[raw/sources/应用工程/提示词工程/第四期：多步编排|第四期：多步编排]]

## 核心结论

自我一致性通过同一提示的多次独立采样和投票，降低单条推理链走偏的风险；链式提示把复杂任务拆成多个串行调用，使每一步目标更窄、中间结果可见且可调试。

## 主要内容

- 自我一致性需要有效的采样多样性，可采用温度、top-k 或核采样；不存在适用于所有模型的最佳温度，独立调用也不保证知识错误相互独立。（[[raw/sources/应用工程/提示词工程/第四期：多步编排#自我一致性：采样后汇总答案|原文采样规则]]）
- 投票前须归一化答案并规定平票、无效格式和证据不足时的处理，投票后仍需外部校验。二元、独立同分布且单次正确率 70% 的简化模型中，13 次严格多数须至少 7 次正确，概率约 93.7625%；这不是模型实测准确率。（[[raw/sources/应用工程/提示词工程/第四期：多步编排#13次投票的正确概率应怎样计算|原文概率算例]]）
- 链式提示把上一步的结构化输出传给下一步，每步都须检查内容、来源和停止条件；通过 JSON 解析不等于事实正确。（[[raw/sources/应用工程/提示词工程/第四期：多步编排#链式提示：拆分、传递与检查|原文阶段验收]]）
- CoT 是单次调用内部的推理过程，链式提示是多次调用之间的工作流，两者可以叠加。
- 采样增加总 Token 消耗；串行调用增加累计延迟，并行墙钟延迟还受排队、并发限制和最长调用影响，不能一概视为 N 倍。复杂且不稳定的任务可在关键子步骤叠加采样，事实仍须原件验证。（[[raw/sources/应用工程/提示词工程/第四期：多步编排#13次投票的正确概率应怎样计算|原文成本边界]]）另一份资料把自我一致性追溯到谷歌 2023 年工作，并强调它提高的是采样后的选答正确率，主模型不会因此变强。（[[wiki/sources/大语言模型：思维链如何用 Token 换取推理计算|思维链的 Token 计算]]）
