# 模型原理：词向量与嵌入矩阵

原始资料：[[raw/sources/模型原理/基础原理/词向量：文字变成数字|词向量：文字变成数字]]

## 核心结论

这一集说明文字怎样变成可以送进模型的向量。一个数分不开的两类点，换成两个数后可以用直线分开；作者据此说二维向量更灵活，也更容易线性可分。这是该例子的结论，没有给出一般条件。升维是从低维变到高维，降维相反。

一个字用一个数不够。大模型面对的最小单位是词元（Token），把句子切开叫做分词（Tokenize）。人工指定每一维的含义几乎做不到。维度等于词表、只有一位为 1 的 one-hot 还有两个问题：维度会跟着词表变大，不同词的点积和余弦相似度都是 0。

word2vec 把词向量排成矩阵，让中间词与上下文的点积变大、与负样本的点积变小。讲解把中心词和上下文各自的矩阵简化成一个。它能出现相似词靠近，以及 $\mathrm{man}-\mathrm{woman}\approx\mathrm{king}-\mathrm{queen}$，但向量是静态的，并常被固定后送给下游任务。BERT 和 GPT 改为随机初始化嵌入矩阵（Embedding Matrix），用 Token ID 取出词嵌入（Token Embedding），再让矩阵随着后续训练更新。画面把它写成一个随机矩阵，由 PyTorch 的 `nn.Embedding` 创建。

下一集才把图中的神经网络具体化。结尾回到定义问题：人决定一个文字变成多少个数，以及把预测下一个词做成词表上的大分类；前 5 名里任选或只取最大，只是架构之外的薄筛选。合适的维度个数要靠实践，本集没有给公式。

## 画面里的数字

性别例子中，2、4、8 是 2 的幂次。二维编号为 $(1,1)$、$(0,1)$、$(1,2)$、$(0,2)$、$(1,3)$、$(1,4)$、$(1,5)$、$(0,3)$，第一个数 0 对应粉色、1 对应黑色。

食物属性是填好的向量的第三个数：我 8、喜欢 2、苹果 89。平面类比只用前两个数：我 $(45,1)$、喜欢 $(2,65)$、苹果 $(22,23)$；香蕉是 $(24,20)$，小米是 $(19,26)$。点积写成 $A\cdot B=\sum_i a_i b_i$，余弦是 $\cos(\theta)=(A\cdot B)/(\|A\|\|B\|)$。“呜了哇啦属性”一列上，作者、飞天、闪客分别是 16、28、99。

word2vec 的演示句是中间词“飞天”，上下文“作者”“闪客”，负样本“帅哥”“富豪”。两句苹果的例子是「我喜欢苹果，不喜欢香蕉」和「我喜欢苹果，但更喜欢小米」。查表例子把「作者飞天闪客」收成 ID 1、4、6；「今天天气真」分成今天、天气、真。代码是 `import torch.nn` 之后的 `vocab_size = 50257`、`embedding_dim = 768`，接着直接调用 `nn.Embedding`。旁白和字幕把 768 说成 GPT2 的词向量维度。总览图在神经网络方框上方标出词表大小 50257，并把其中一个输出位置标成「好」。这些都是教学图上的数。

## 与其他资料的边界

[[wiki/sources/模型原理：定义问题，预测下一个词|定义问题]] 把任务定义成预测下一个词，并留下一个词怎样变成一组数。本集补的是这组数，不是 FFN 的 768、3072、768，也没有解释 GELU。两集都出现 768 和 50257：上一集说线性层从 768 到 50257，本集的代码把词表大小和嵌入维度写成这两个数，旁白只把 768 说成 GPT-2。总览图上的 50257 与「好」只说明输出落在词表上，没有展开方框里的层。这仍不是 [[wiki/sources/模型架构：Linear、Activation 与 MLP|GPT-2 XL]] 的 1600 维。

[[wiki/sources/大语言模型：Tokenizer、Token ID 与 BPE|Tokenizer]] 比较按词、按字符和 BPE。本集只把分词说成把句子切成词元并用 ID 查表，没有合并规则，不能补成 BPE。[[wiki/sources/大语言模型：Token、Embedding 与 Latent Space|Token 与 Embedding]] 区分 Token Embedding、Hidden State 和 RAG Embedding。本集的嵌入矩阵是生成模型的初始词向量，没有讨论隐藏状态，也不能当成检索向量。

[[wiki/sources/大语言模型：Abliteration 与拒绝方向干预|Abliteration]] 用国王与女王的向量关系作直观启发，并说明这不证明每个概念都是单一方向。本集展示的是 $\mathrm{man}-\mathrm{woman}\approx\mathrm{king}-\mathrm{queen}$，两者不能合成同一条语义算术定律。

结尾说前 5 名可以随便选，或只选最大的一个。这是输出形式的例子，没有给出采样温度或其他解码算法。

原示例写 `import torch.nn`，随后调用 `nn.Embedding`，没有为 `nn` 绑定名称；该片段不能直接独立运行。这里保留来源写法，不把它作为可执行代码。（[[raw/sources/模型原理/基础原理/词向量：文字变成数字#嵌入矩阵跟着模型一起变|来源代码]]）
