# 模型原理：词向量与嵌入矩阵

原始资料：[[raw/sources/模型原理/基础原理/词向量：文字变成数字|词向量：文字变成数字]]

## 核心结论

Tokenizer 将文本切成词元并映射为 ID，嵌入矩阵按 ID 提供初始向量。ID 是索引，不代表词义大小。one-hot 的维度等于词表大小，不同词向量正交；低维稠密词嵌入以训练所得数值表达关系，不能预先把每维指定为稳定的人类概念。

来源以 word2vec 的中心词、上下文和负样本说明静态表示；讲解将中心与上下文的两套矩阵简化成一套。BERT、GPT 使用随机初始化并随模型训练更新的嵌入矩阵，后续上下文化计算与初始查表分别讨论。

## 画面里的数字

教学查表把「作者飞天闪客」映射为 ID 1、4、6；「今天天气真」切成今天、天气、真。来源代码设置 `vocab_size = 50257`、`embedding_dim = 768`，用 `nn.Embedding` 创建矩阵；768 被称为 GPT-2 词向量维度。

点积与余弦分别为 $A\cdot B=\sum_i a_i b_i$ 与 $\cos\theta=(A\cdot B)/(\|A\|\|B\|)$。来源的 $\mathrm{man}-\mathrm{woman}\approx\mathrm{king}-\mathrm{queen}$ 是语义关系示例，不构成所有概念都由单一方向表达的定律。

## 与其他资料的边界

本篇介绍初始 Token Embedding，未给 BPE 合并规则，也没有把词向量用于 RAG 检索。生成模型的隐藏状态与检索 Embedding 见 [[wiki/sources/大语言模型：Token、Embedding 与 Latent Space|表示位置与用途]]。

升维使两类教学点线性可分，只适用于该例，不是任意升维必然可分的结论。输出取前 5 名之一或最高分仅是筛选示意，没有温度及完整解码配置。

原示例写 `import torch.nn` 后直接调用 `nn.Embedding`，没有绑定 `nn` 名称，片段不能独立运行。（[[raw/sources/模型原理/基础原理/词向量：文字变成数字#嵌入矩阵跟着模型一起变|来源代码]]）
