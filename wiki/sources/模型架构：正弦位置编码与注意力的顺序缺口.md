# 模型架构：正弦位置编码与注意力的顺序缺口

原始资料：[[raw/sources/模型原理/模型架构/Transformer为什么需要位置编码|Transformer为什么需要位置编码]]

## 核心结论

最朴素的 Attention 只根据 Query 与 Key 的匹配结果对 Value 加权求和。若前序 Token 只是换序，Key 的分数项和对应 Value 会一起换序，而求和结果不变；模型因此需要在 Embedding 中加入位置信息，才能区分“张三打李四”和“李四打张三”这类词相同、顺序不同的输入。

资料依次比较三种直接方案：绝对位置值可能压过 Embedding 中的数值，$pos/L$ 会让同一位置随序列总长改变，二进制编码虽然值域固定且与总长无关，却在相邻位置间发生多位跳变。正弦位置编码保留了二进制的多尺度结构，同时把方波换成连续的正弦波。

## 编码结构

原始 Transformer 的正弦位置编码把维度两两分组：

$$
\operatorname{PE}_{(pos,2i)}=\sin\left(\frac{pos}{10000^{2i/d}}\right),\qquad
\operatorname{PE}_{(pos,2i+1)}=\cos\left(\frac{pos}{10000^{2i/d}}\right)
$$

编码值位于 $[-1,1]$，并且只依赖位置 $pos$，不依赖序列总长度。第 $i$ 组的波长为：

$$
\lambda_i=2\pi\cdot10000^{2i/d}
$$

低维组变化快，高维组变化慢。令 $\omega_i=1/10000^{2i/d}$ 后，每组正弦与余弦可以看作单位圆上一根转速为 $\omega_i$ 的指针；多组不同转速的指针共同表示一个位置。

## 示例与边界

- 位置 24 的六位二进制是 `011000`；位置 23 是 `010111`，二者相邻却有四位变化。
- 当 $d=8$ 时，前两组波长分别为 $2\pi$ 和 $20\pi$，后续各组按 10 倍增长。一般公式中的最高维波长随维数增加而接近 $2\pi\times10000$。
- “约六万个 Token 才重复，因此足以区分普通上下文”是资料用于解释底数 10000 的教学口径。资料没有讨论有限精度、训练外长度泛化、可学习位置编码或 RoPE，不能由本期资料比较这些方案的实际效果。
