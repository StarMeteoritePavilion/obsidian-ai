# 模型训练：梯度下降与均方误差

原始资料：[[raw/sources/模型工程/训练与后训练/大模型的训练原理 梯度下降：从一条直线讲起|大模型的训练原理 梯度下降：从一条直线讲起]]

## 核心结论

梯度下降先用损失函数衡量模型输出与训练目标的差距，再根据损失对参数的梯度确定更新方向，并由学习率控制每次更新的距离。模型参数来自数据训练，Learning Rate 与 Batch Size 则是人为设置的超参数。

## 从平方误差到参数更新

资料以 $y_{out}=wx+b$ 为模型，以 $x_{train}=2$、$y_{train}=5.6$ 为单条样本，并把 $w$、$b$ 初始化为 $0.5$、$1$。平方误差写为 $(y_{out}-y_{train})^2$；固定 $b$ 后，对 $w$ 的损失为 $(2w-4.6)^2$，在 $w=0.5$ 时梯度为 $-14.4$。使用学习率 $0.01$ 后，$w$ 更新为 $0.644$。

同一轮中，$b$ 的梯度仍使用更新前的 $w=0.5$ 计算。此时损失为 $(b-4.6)^2$，导数为 $2b-9.2$；在 $b=1$ 时梯度为 $-7.2$，更新后得到 $b=1.072$。视频画面给出的这组公式能够与样本、梯度和更新结果相互验证。

## 批量训练与 MSE

单个偏离较远的数据点可能把参数拉向其他方向。资料一次取 100 个样本，分别计算平方误差后求平均，得到均方误差（Mean Squared Error，MSE）；每批使用的样本数即 Batch Size。批量损失减弱了单个样本的影响，但没有改变根据梯度更新 $w$ 与 $b$ 的基本过程。

资料还区分了模型函数和损失函数：前者根据输入产生预测，后者衡量预测与训练目标的差距。求某个参数的梯度时，当前参数是求导变量，训练输入与目标则是已知量。

## 演示结果与边界

示例用 Batch Size 100、Learning Rate 0.01 训练 1000 次，最终得到 $y=1.4994x+2.4845$，接近生成数据时使用的 $y=1.5x+2.5$。这些参数、超参数与收敛结果只属于该线性回归教学实验，不构成其他模型的默认训练配置或收敛保证。
