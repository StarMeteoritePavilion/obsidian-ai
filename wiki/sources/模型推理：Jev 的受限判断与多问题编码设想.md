# 模型推理：Jev 的受限判断与多问题编码设想

原始资料：[[raw/sources/模型原理/基础原理/Jev的原理是什么？]]。

## 核心结论

来源用评论分类区分自由文字生成与受限判断。Jev 被介绍为接收内容和多个问题，返回选择、是非、评分结果及概率的模型；节省逐 Token 组织自由回复的过程，是作者解释其速度与接口特点的核心。关于内部如何实现，作者明确声明TypeSafe公司未公开方案，BERT式填空、多个答案占位符与答案Embedding均是他的技术推演，不是已经核实的产品架构。（[[raw/sources/模型原理/基础原理/Jev的原理是什么？#Jev 的接口：给定问题，直接返回结果与概率|接口介绍]]、[[raw/sources/模型原理/基础原理/Jev的原理是什么？#作者的实现推演：从文字接龙改为填空|实现归属]]）

## 从生成标签到限定选项

- **三项问题**：逐 Token 输出增加生成步骤；答案可能带标点、解释或混合标签；单个标签没有呈现判断倾向。每字一步及“中评”两步属于教学示意，不能替代具体Tokenizer的计数与推理耗时。（[[raw/sources/模型原理/基础原理/Jev的原理是什么？#用生成式大模型分类评论的三个问题|三项问题]]）
- **首 Token 概率方案**：在“好／中／差”分别为9%、63%、18%、其余合计10%的例子中，将前三者除以90%，得到10%、70%、20%。该方案在一轮内形成限定选项结果与相对概率，但首字相同的“餐品洒漏／餐品变凉”需要继续比较，多个问题也不能只靠同一个下一 Token 分布分别取答。（[[raw/sources/模型原理/基础原理/Jev的原理是什么？#只读取首个 Token 的概率，能解决多少问题？|归一化与两个漏洞]]）
- **产品能力的来源介绍**：选择题最多255个选项；是非题返回“是”的概率；评分例为生气程度1—5。作者称一次请求可包含多个问题并一起返回。这些能力来自作者介绍，现有资料缺少接口文档与独立测试，不能据此确认具体字段、完整逐档分布或当前服务承诺。（[[raw/sources/模型原理/基础原理/Jev的原理是什么？#Jev 的接口：给定问题，直接返回结果与概率|三类问题]]）

## 作者提出的编码与训练方案

作者从自回归预测后续词元与BERT恢复遮盖词元的区别出发，设想将评论与多个“问题＋占位符”一起编码，让不同答案位置同时形成表示。示例标注为中评、退款概率60%、生气2分；新输入仍使用多个问题及答案位置。这不是只读取生成模型最后一个位置的词表概率。（[[raw/sources/模型原理/基础原理/Jev的原理是什么？#作者的实现推演：从文字接龙改为填空|训练任务与多位置输入]]）

为摆脱占位符只恢复词元的形式，他设想直接预测答案Embedding，并与选项Embedding做点积。三维例中，预测向量`[0.9, 0.1, 0.1]`与好评、中评、差评的点积分别为0.36、0.84、0.21，中评得分最高；再将分数换算成概率。是非题与评分题分别比较两类答案及1—5档答案的表示。训练被直观解释为按预测与正确答案表示的距离调整，越近越奖励、越远越惩罚；题目和选项足够丰富后能够回答新选项，是作者提出的泛化判断，现有资料没有独立实验支持。（[[raw/sources/模型原理/基础原理/Jev的原理是什么？#用答案 Embedding 连接表示与选项|向量、打分与训练]]）

## 适用范围

1. **相对概率不等于已校准的正确率**：70%只是在所选三个首Token中重新归一化的结果，原来其余Token的10%被排除。来源称它是判断的“把握”，但没有提供概率校准、真实正确率或分布外测试；不能把70%直接当作类似样本中70%必然判对。Jev返回概率的产品介绍也没有自动解决校准问题。
2. **点积分数还不是概率**：0.36、0.84、0.21均为给定向量的乘积求和。来源没有给出分数到概率的精确函数、参数、归一化或损失定义，这些数值不足以确定具体Softmax温度、余弦相似度或强化学习算法。“奖励／惩罚”是训练目标的直观说法。
3. **一次处理多个答案位置，不是无限问题零成本**：一次运行是作者所介绍的能力与方案目标；没有硬件、输入长度、问题数量、批量、准确率及延迟测量，不能形成任意负载的速度保证。“输出免费”是价格口径，仍返回结构化答案与概率，并非没有输出数据。
4. **保留生成示例的适用范围**：原文采用最高概率选字解释接龙，并不说明所有生成模型只能贪心解码。首Token方法“一题一跑”的限制也不等同于通用模型不能在一次请求中回答多题；本篇没有逐一比较结构化输出、受限解码或其他分类方案。
5. **架构类比不等于训练任务相同**：作者将BERT与Vision Transformer类比为编码输入的结构，不能据此认定ViT也执行文字掩码任务，或所有Embedding都具有相同的语义距离和训练目标。首字、Token、答案向量及类别概率属于不同对象。
6. **认知类比不证明思维链无用**：判断是否在首字前已经形成，是作者的疑问；加扎尼加裂脑研究的转述和车内独处场景是结尾类比，不是模型内部机制的实验。不能由此得出所有思维链都是事后编理由的结论。
