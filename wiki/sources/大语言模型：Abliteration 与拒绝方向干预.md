# 大语言模型：Abliteration 与拒绝方向干预

原始资料：[[raw/sources/模型原理/基础原理/LLM Abliteration 是什么]]。

## 核心结论

来源通过 Arditi 等人 2024 年的研究介绍 Abliteration：从有害与无害提示的逐层残差均值差中提取方向，再用删除、添加和正常输出分布检查筛选拒绝方向；还可将方向投影的删除写入相关权重矩阵，无需微调或重新训练。这是对所述实验与方法的转述，不能把“处理后不再拒绝”推广为任意模型、请求及安全机制的保证。（[[raw/sources/模型原理/基础原理/LLM Abliteration 是什么#从词向量关系到拒绝方向|实验对象]]、[[raw/sources/模型原理/基础原理/LLM Abliteration 是什么#从动态干预到直接修改权重|权重处理]]）

## 方法与证据链

1. **确定表示位置**：残差流累加 Embedding 与逐层注意力、MLP 的写入。4096 维、32 层是来源的架构示例，不是所有模型的固定配置。（[[raw/sources/模型原理/基础原理/LLM Abliteration 是什么#残差流：各模块共同写入的数据主干|残差连接]]）
2. **提取组间差异**：有害与无害提示各 128 条；在聊天格式的回答起始相关位置记录逐层残差，各组按层平均，再用有害均值减无害均值。作者以 32 层说明 32 个差向量；研究在多个相关标记位置做处理，不能将简化的 `assistant` 当作所有模型通用的最后 Token。（[[raw/sources/模型原理/基础原理/LLM Abliteration 是什么#用两组提示词提取方向|数据与位置]]）
3. **验证方向作用**：在各层、各 Token 的残差中删除同一方向的投影，观察有害问题的拒绝开头概率是否下降；向无害问题添加方向，检验是否诱发拒绝。这里检验的是同一模型各层、各位置共享方向的假设，不是 13 个模型共享一根向量。（[[raw/sources/模型原理/基础原理/LLM Abliteration 是什么#用干预与分布变化筛选方向|删除与添加]]）
4. **约束正常行为变化**：原模型与干预后模型对同一无害问题的下一 Token 分布以 KL 散度比较，差异太大的方向淘汰。这项检查不能单独证明全部任务能力、长期行为或安全性均保持。（[[raw/sources/模型原理/基础原理/LLM Abliteration 是什么#用 KL 散度排除破坏正常输出的方向|分布检查]]）
5. **将运行时干预写入权重**：来源公式为 $W'=W-\hat r\hat r^{T}W$，其中 $\hat r$ 的长度为 1；修改的是向残差流写入信息的相关矩阵。无需重新训练并不等于不改变权重。（[[raw/sources/模型原理/基础原理/LLM Abliteration 是什么#从动态干预到直接修改权重|矩阵公式与部署形态]]）

## 解释边界

- 来源称研究测试 Llama、Qwen、Gemma 等 13 个开源模型；“各自存在一个方向”限定于所述研究对象。Word2Vec 的国王与女王向量关系提供直观启发，不证明所有概念都由单一方向完整表示。（[[raw/sources/模型原理/基础原理/LLM Abliteration 是什么#从词向量关系到拒绝方向|类比与实验]]）
- 求平均抵消主题差异、相减消除请求共同成分，是来源的研究思路；其效果由后续干预实验检验，不能把样本分组本身当作因果识别已经成立。（[[raw/sources/模型原理/基础原理/LLM Abliteration 是什么#逐层求平均，再比较两组差异|均值差解释]]）
- 首 Token 的拒绝式开头概率是本篇介绍的筛选信号；没有生成完整回答的这一检查，不等于对完整输出是否正确、有害或任务成功作出评判。来源未给出具体筛选阈值、KL 门槛或完整复现实验配置。（[[raw/sources/模型原理/基础原理/LLM Abliteration 是什么#既检查删除，也检查反向添加|开头概率]]、[[raw/sources/模型原理/基础原理/LLM Abliteration 是什么#用 KL 散度排除破坏正常输出的方向|KL 检查]]）
- 权重公式采用来源图示的矩阵方向约定；本文没有给出各架构张量布局及实现，不能直接把画面中的 $W$ 对应到未经读取的具体参数名。未运行 `abliterator` 或复现权重修改。
- 结尾有关真假、讨好及人格的说明，分别保留为来源提及的研究和探索性联想。正文没有展开前两项研究的实验范围，也没有证明模型具有人格或所有概念都能还原为几根箭头。（[[raw/sources/模型原理/基础原理/LLM Abliteration 是什么#概念是否都能表现为方向？|结尾范围]]）
