# 提示词工程：第六期 Anthropic 工程规范

原始资料：[[raw/sources/应用工程/提示词工程/第六期：Anthropic 工程规范|第六期：Anthropic 工程规范]]

## 核心结论

生产提示应把不同类型的内容结构化分区，把稳定规则放入 system prompt，并通过长内容置顶、先引后答、正向输出指令和“先读后答”约束提升可迁移性与可验证性。

## 六项规范

1. 用 XML 标签区分指令、文档和示例。
2. 用 system prompt 承载角色、底线和全局规则。
3. 长文档放前面，问题放末尾；先提取相关引文，再据此回答。
4. 让支持该能力的模型自适应决定推理投入。
5. 对被引用的代码或文件要求先读取再回答，缺少证据时不编造。
6. 用“应输出什么”的正向指令取代模糊的否定约束。

## 使用边界

原文包含 Claude 版本行为、迁移要求和效果数字。实际接入具体模型或 API 时，应再核对对应版本的官方文档，不能把版本相关结论视为永久规则。
