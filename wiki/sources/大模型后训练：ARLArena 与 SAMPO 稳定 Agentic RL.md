# 大模型后训练：ARLArena 与 SAMPO 稳定 Agentic RL

原始资料：[[raw/sources/模型工程/训练与后训练/ARLArena：4B小模型用SAMPO训练，Agent任务成功率碾压GPT-5.2|ARLArena：4B 小模型用 SAMPO 训练]]

## 核心结论

ARLArena 在统一测试台中把策略梯度拆成损失聚合、重要性采样裁剪、优势函数设计和动态采样四个维度。资料将训练崩塌的主要来源归于负优势、低重要性采样比率的序列持续参与更新：容忍型裁剪在重要性采样比率越界后仍保留梯度，使本应停止参与更新的危险序列持续影响策略，并可能累积为梯度爆炸。SAMPO 通过序列级裁剪、细粒度步骤级优势和动态采样共同缓解这一问题。

稳定训练不能只靠更换单个优化器组件。行为克隆初始化、格式惩罚和 KL 正则化先建立合理行为范围；裁剪、优势和采样之间还存在交互效应，分别有效的设计直接组合后不保证继续有效。

## 三项关键机制

序列级裁剪对一条轨迹全部 Token 的重要性采样比率取几何平均，再决定整条序列是否参与更新，避免少数极端 Token 控制轨迹梯度。论文实验把它列为稳定性影响最显著的单项设计。

GiGPO 的步骤级优势在相同环境状态下比较不同轨迹的动作选择，把整条轨迹共享的总分细化为局部相对信号。动态采样则过滤全成功或全失败、组内优势为零的轨迹；它与 GRPO 直接结合会损失早期格式学习信号，配合更丰富的步骤级优势后才稳定发挥作用。

## 实验与比较边界

ARLArena 的对比表使用 Qwen3-4B 的 SFT 版本，覆盖 ALFWorld、WebShop、Sokoban 和 TIR Math。SAMPO 在 ALFWorld 上达到 92.72% 成功率，GRPO 为 62.36%；在 Sokoban 上，CISPO、SAPO、GRPO 和 SAMPO 分别为 26.02%、30.25%、83.90% 和 88.86%。论文汇总表把 SAMPO 平均结果记为 60.21，并标注平均提升 25.2%，但 SAMPO 行没有 TIR Math 结果；资料旁白所称“在四个任务上”全面超过对比方法与官方表格不一致，不能据此补全。

资料另列出 ALFWorld 上 GPT-5.2 单 Agent 51.56%、o3 Multi-Agent 56.25% 和 Qwen3-4B SAMPO 92.72%。前两者没有接受相同的环境专项训练，不能据此形成通用模型能力排名，也不能把受控任务结果直接外推到真实开放式 Web Agent。

## 与现有知识的整合

该资料补充了 Agent RL 路线中的优化稳定性层：奖励来源和轨迹粒度确定之后，还需要控制旧策略数据与当前策略之间的偏差，并让裁剪、信用分配和采样过滤协同工作。它也进一步说明训练奖励与独立评测必须分工，受控环境上的专项成功率不等于开放环境中的通用可靠性。
