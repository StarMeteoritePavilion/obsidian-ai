# 模型原理：模型训练，预训练、后训练与思维链

原始资料：[[raw/sources/模型原理/基础原理/模型训练：预训练、后训练与思维链]]

## 核心结论

预训练以文本自身的后继词元构造自监督目标，各位置可并行参与训练；推理则利用最后位置逐步生成。来源用高质量问答的监督微调（SFT）解释后训练，使模型由续写文本转向遵循任务要求。

少样本学习在提示中提供示例，思维链提示要求生成中间过程；这两种推理时操作不改变参数或架构。强化学习仅列出 RLHF 与 RLVR，没有给完整算法。生成可见步骤也不构成模型会可靠解决所有语言任务的证明。

## 不能补完的例子

苹果题初始 23 个，吃 5 个、买 12 个、再送 7 个；可见模型回答只完成 $23-5=18$ 与 $18+12=30$。来源没有展示最终减去 7 的回答，不据此计为解题成功。

GLM-5.3 与 GLM-5.2 共用基础模型、提升来自后训练，是资料引用页面的说法；本篇没有相同配置的独立评测支持，不用于泛化评价后训练收益。

## 与其他资料的边界

SFT 是本篇采用的后训练示例，不是全部后训练方式。反馈来源和策略优化分别见 [[wiki/sources/大模型后训练：强化学习如何选择反馈与算法|后训练与强化学习]]。思维链的测试时计算、选答与训练作用分别见 [[wiki/sources/大语言模型：思维链如何用 Token 换取推理计算|思维链计算]]；本讲没有正确率或训练过程数字。
