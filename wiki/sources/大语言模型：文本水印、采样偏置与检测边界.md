# 大语言模型：文本水印、采样偏置与检测边界

原始资料：[[raw/sources/模型原理/基础原理/AI水印到底藏哪了？]]。

## 核心结论

文本水印既可以通过插入隐藏字符实现，也可以介入 Token 采样，使输出留下可由持有相应密钥者重建的统计信号。来源依次介绍固定红绿分组、KGW 动态分组与加分、Aaronson 伪随机选择的简化说明，以及 SynthID-Text 的抽样淘汰示例。它们修改的环节和检测条件不同，不能把“文本中没有隐藏字符”等同于“没有水印”。（[[raw/sources/模型原理/基础原理/AI水印到底藏哪了？#隐藏字符：容易添加，也容易清除|字符标记]]、[[raw/sources/模型原理/基础原理/AI水印到底藏哪了？#KGW：动态红绿分组与概率偏置|动态分组]]、[[raw/sources/模型原理/基础原理/AI水印到底藏哪了？#SynthID-Text：保留随机抽样，再进行多轮淘汰|抽样淘汰]]）

## 方法及采用条件

- **隐藏字符**：来源以 `U+200B`、`U+200C` 说明排版字符与不可见标记；o3 演示中的较窄空格为 `U+202F`，与普通空格 `U+0020` 对比。看见特殊字符本身不能证明它由厂商有意植入为水印，更不能证明某一产品所有输出都采用该方案。（[[raw/sources/模型原理/基础原理/AI水印到底藏哪了？#隐藏字符：容易添加，也容易清除|用途与作者推测]]）
- **KGW**：来源用密钥与前一个 Token 动态划分红绿组，对绿组加分而保留红组；检测重建每步分组并统计绿组偏向。概率示例为“好”50%、“不错”30%、“棒”15%、其余5%；加分后的“不错”60%与“好”30%只作机制示意，不是完整实现参数。固定词表禁用红组会限制表达，动态加分仍可能改变最合适的用词。（[[raw/sources/模型原理/基础原理/AI水印到底藏哪了？#每一步重新分组，允许红组继续出现|生成]]、[[raw/sources/模型原理/基础原理/AI水印到底藏哪了？#检测整篇比例，不能只检查是否出现红组词|检测]]）
- **Aaronson 思路的教学简化**：作者用按概率划分 `[0,1]`、用密钥和前一 Token 生成伪随机数替换普通随机数，说明可重算选择与重复回复问题；没有提供完整算法或验证器。此说明不宜当作 Aaronson 原始方案的完整技术定义。（[[raw/sources/模型原理/基础原理/AI水印到底藏哪了？#Aaronson 水印：用可重算的伪随机数参与采样|简化说明]]）
- **SynthID-Text**：本例独立抽样8次，5个“好”、2个“不错”、1个“棒”；密钥、前一 Token、当前 Token与轮数共同决定虚拟硬币，同轮相同 Token 的硬币必须相同。两两配对，正反不同时正面晋级、相同时任选，逐轮计算至剩一个。检测利用输出的正面偏向；8次抽样是本例设置，不是全部部署的固定要求。（[[raw/sources/模型原理/基础原理/AI水印到底藏哪了？#先独立抽样，再给选项分配硬币|抽样与硬币规则]]、[[raw/sources/模型原理/基础原理/AI水印到底藏哪了？#淘汰规则留下可检测的统计偏向|检测信号]]）

## 统计与算法边界

1. **尾概率不是作者身份的后验概率**。来源画面按二项分布计算：200个 Token 中至少155个为绿，在每次独立且绿组概率为 $1/2$ 的假设下，尾概率约 $1.1986\times10^{-15}$。本次用整数二项式求和复核，和画面约 $1.2\times10^{-15}$ 一致。它表示该基线假设下出现如此偏向的稀有程度，不等于“此文由人写的概率”，也不包含真实流量的基率、误报率或检测阈值校准。4个 Token 全绿的 $1/16$ 同样受该假设约束。（[[raw/sources/模型原理/基础原理/AI水印到底藏哪了？#检测整篇比例，不能只检查是否出现红组词|数字与短文本例]]）
2. **未检出不等于人工创作**。来源以“红绿／正反接近各半”说明人工基线；具体检测针对相应水印机制和密钥，不能由缺少该信号认定文字必定由人撰写，也不能用“最先进之一”的作者评价替代误报与漏报测量。（[[raw/sources/模型原理/基础原理/AI水印到底藏哪了？#淘汰规则留下可检测的统计偏向|教学判别]]）
3. **伪随机数相同，不单独决定所有上下文的 Token**。按来源的区间图，同一个数落入哪个 Token 区间，还取决于当前概率划分。不能把“前一 Token 相同就选同一 Token”推广到任意完整上下文；检测若要恢复区间选择，也需明确相应概率信息与模型条件。来源未展开这些条件，本库保留其简化说明，未据此编写验证器。（[[raw/sources/模型原理/基础原理/AI水印到底藏哪了？#Aaronson 水印：用可重算的伪随机数参与采样|区间图与重复问题]]）
4. **平均概率接近不表示逐次输出相同**。来源对 SynthID-Text 的论述强调平均选择概率与原分布接近，同时保留随机性；没有给出形式化证明、重复上下文处理、密钥平均的确切范围或部署配置。“统计破解难度指数级增加”也仅是作者对KGW的概括，不能用作已验证的安全复杂度结论。（[[raw/sources/模型原理/基础原理/AI水印到底藏哪了？#先独立抽样，再给选项分配硬币|平均概率]]、[[raw/sources/模型原理/基础原理/AI水印到底藏哪了？#每一步重新分组，允许红组继续出现|破解难度说法]]）
5. **编辑稳健性须区分实现和条件**。少量修改不明显影响统计、大量改写理论上可去除，以及无水印模型多次重写，均是作者介绍的边界；本次未测量具体改写比例、攻击成功率或质量代价，不作普遍成功或普遍不可移除的保证。（[[raw/sources/模型原理/基础原理/AI水印到底藏哪了？#改写能否去除水印？|编辑与质量]]）
