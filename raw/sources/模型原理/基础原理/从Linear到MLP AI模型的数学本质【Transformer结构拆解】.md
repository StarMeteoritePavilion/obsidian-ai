# 从线性层到 MLP：Transformer 前馈网络的数学基础

> “从0开始一起学大模型”合集第二条／Transformer 结构拆解续篇

Transformer 中的线性（Linear）与前馈网络（Feed Forward）模块，归根结底是对多维数组（张量）执行的数值计算。文字或图片转换为数字矩阵后，通过线性变换与非线性激活，在模型内部完成特征映射。

理解线性层和激活函数，有助于判断前馈网络接收什么、产生什么，以及它们在 Transformer 内部是如何协同工作的。

## 仿射变换：数学形式与张量计算

在严格的线性代数中，线性变换保持原点不动。但在深度学习中，线性层（Linear Layer）实际上执行的是仿射变换（Affine Transformation）：不仅包含权重的线性组合，还会加入偏置。

假设输入为向量 $x = [x_1, x_2, x_3, x_4]$，让每个输入乘以对应的权重系数 $w_i$，再相加并加入一个偏置常数 $b$，就能得到一个输出值：

$$
y = w_1x_1 + w_2x_2 + w_3x_3 + w_4x_4 + b
$$

举个例子，如果要将一个包含 4 项活动数据的输入，映射到两个输出维度上，则需要两组独立的权重和偏置。模型就是通过这样的矩阵乘法和加法，将 4 维输入向量映射为 2 维输出向量。

在现代深度学习框架中，线性层处理的通常是批量数据，并且专门在张量的最后一维上进行操作。如果输入张量的形状为 `[batch_size, seq_len, in_features]`，线性层权重矩阵的形状为 `[out_features, in_features]`，偏置的形状为 `[out_features]`。线性层会将输入的最后一维 `in_features` 映射到 `out_features`，输出张量形状最终变为 `[batch_size, seq_len, out_features]`。

## 训练参数：损失、梯度与参数更新

像前面活动映射例子中的系数，如果是手工设计的，每个参数的含义都非常明确。但在庞大且复杂的深度网络中，线性层的参数都是通过训练在数据中寻找的。

训练开始时，模型权重和偏置通常初始化为随机数。输入数据后，通过正向计算得到预测结果，利用损失函数（Loss Function）衡量预测值与正确结果的差距。通过反向传播算法计算损失对每个参数的梯度（Gradient），指示了减小误差的方向。最后，优化器根据梯度更新所有参数。

这个过程反复进行，直到模型输出逼近真实数据。训练完成后，整组参数在目标任务上能够产生预期的映射效果，但这通常不意味着我们可以为每个中间参数赋予人类可读的具体解释。

## 线性层叠加仍为线性

单一的线性变换所能表达的规律非常有限。如果我们试图直接把多个线性层连在一起，希望拟合更复杂的关系，结果会怎样呢？

假设第一层计算 $y = W_1 x + b_1$，第二层计算 $z = W_2 y + b_2$，把前者代入后者：

$$
z = W_2 (W_1 x + b_1) + b_2 = (W_2 W_1) x + (W_2 b_1 + b_2)
$$

由于矩阵乘法的结合律，合并后的结果等价于一个新的权重矩阵 $W_{new} = W_2 W_1$ 和新的偏置 $b_{new} = W_2 b_1 + b_2$ 所作的单一线性（仿射）变换。无论连续堆叠多少个线性层，模型整体依然只能表达线性映射，无法拟合现实世界中复杂的非线性曲线。

## 激活函数引入非线性

为了打破线性层的局限，必须在它们之间加入非线性计算，这就是激活函数（Activation Function）。它们不包含任何可训练参数，仅对输入数值进行固定的非线性映射。

在深度学习的发展历程中，几种主流的激活函数各有特点：

- **Sigmoid 与 tanh**：它们是平滑的非线性函数，能够将输入压缩到一个固定的范围。但在输入绝对值较大时，其梯度趋近于 0，容易导致训练中的“梯度消失”问题。
- **ReLU（Rectified Linear Unit）**：形式极简，$\operatorname{ReLU}(x)=\max(0,x)$。它在历史背景下有着重要的计算优势，且在正数区间保持梯度为 1，有效缓解了梯度消失，因此在早期的许多卷积网络和多层感知机中得到广泛应用。
- **GELU（Gaussian Error Linear Unit）与 Swish**：在现代语言模型（如 BERT、GPT 等）中，单纯截断负数的 ReLU 已很少使用。GELU 结合了 ReLU 的计算效率与平滑过渡，在负数区域保留了微小的梯度。现代架构还常使用 SwiGLU 等门控激活结构，能取得更优的非线性映射效果。

## MLP/FFN：前馈网络的组成

将线性层与激活函数交替连接，就形成了前馈神经网络（Feed-Forward Network，FFN），或称多层感知机（Multi-Layer Perceptron，MLP）。这就是 Transformer 结构中 Feed Forward 模块的骨架。

例如，拟合一条带有非线性拐点的复杂曲线，可以通过 3 个线性层和 2 个激活函数完成：
1. 第一层把 1 个输入维度映射为 128 维表示。
2. 应用激活函数（如 ReLU）。
3. 第二层把 128 维表示映射为 256 维。
4. 应用激活函数。
5. 第三层把 256 维映射回 1 个输出值。

在这个 1→128→256→1 的例子中，每一层都包含了完整的权重和偏置：
- 第一层参数：$1 \times 128$（权重）$+ 128$（偏置）$= 256$
- 第二层参数：$128 \times 256$（权重）$+ 256$（偏置）$= 33,024$
- 第三层参数：$256 \times 1$（权重）$+ 1$（偏置）$= 257$

网络总计有 33,537 个可训练参数。正是这些交替的线性和非线性计算，赋予了模型充足的拟合能力。

## Transformer 中的位置

在 Transformer 架构中，前馈网络模块扮演着不可或缺的角色。现代 Transformer 的 FFN 常常采用“扩维—激活／门控—降维”的结构：第一个线性层将输入向量在隐藏维度上放大（通常扩大 4 倍或更高），应用 GELU 或 SwiGLU 等非线性激活机制处理后，第二个线性层再将其压缩回原本的隐藏维度。这种先升维再降维的方式极大增强了每个 Token 独立处理时的特征表达能力。

以采用了 Transformer Decoder 架构的 GPT-2 XL 为例：其模型内部的隐藏维度（Hidden Size）为 1600。当数据流动到整个网络的输出端时，会通过一个最后一层的线性映射（输出投影），将 1600 维的内部特征映射到 50,257 维，从而对应 GPT-2 的 50,257 词表大小，预测下一个可能的 Token。在这个过程中，输出投影层的权重通常与最初负责输入 Token 映射的 Embedding 层权重共享（Weight Tying），以此来让输入和输出共享同一套词元特征空间并节省大量参数。

## 总结

线性层（仿射变换）利用权重和偏置，在给定的最后一个维度上实现向量特征空间的映射；模型训练则是通过损失函数和梯度来迭代更新这些参数。直接串联多个线性层只能表达线性关系，但激活函数在层间引入了非线性。两者交替组合形成的 MLP（或 FFN），构成了 Transformer 内部强大的表示模块。通过明确这些模块的数学作用，我们能够清晰理解大规模模型是如何组合这些基础组件来近似复杂规律的。
