# AI水印到底藏哪了？

> 从隐藏字符到采样过程中的统计标记

图片水印可以是半透明的标志，也可以藏在不明显的像素里。文字没有同样的图像空间，水印究竟能藏在哪里？答案既可能是肉眼看不见的字符，也可能是整篇文字在选词过程中留下的统计规律。

作者以欧盟人工智能法案与厂商响应引出这个问题。他称，欧盟要求 AI 生成内容带有标记，两周后 Claude 宣布生成文字会带上水印；在他看来，欧洲的模型研发能力与监管积极程度并不相称。以下围绕文字水印的几种实现思路展开。

## 隐藏字符：容易添加，也容易清除

零宽字符的显示宽度为零，主要供程序排版使用，并非直接给人阅读。

- `U+200B` 是零宽空格，可在泰文和高棉文中提示允许换行的位置。
- `U+200C` 是零宽不连字，可在波斯语中阻止字母连写。

最简单的文字水印，就是在正文中插入几个看不见的字符。

作者提到，2025 年有人发现 OpenAI 的 o3 回答偶尔混入较窄的空格，肉眼很难与普通空格区分。他据此怀疑这是一种水印，同时明确说 OpenAI 并未承认。作者还称，Claude 在 2026 年曾用隐藏字符给中国用户生成的内容打标签。

这类方法的弱点是容易发现，也容易清除。只要找出所用字符，用文字软件执行查找替换，就能去掉对应标记。

## 采样：相同意思，可以用不同的词表达

大模型通过逐步生成 Token 续写文字。假设已经生成“今天天气真”，下一步可能的选择是：“好”50%、“不错”30%、“棒”15%，其他 Token 合计 5%。

通常，模型不是直接取概率最大的一个，而是按概率抽样。“好”更容易被选中，低概率的词也仍有机会。因此，相同问题问两次，往往会得到不同表述。

对作者而言，“今天天气真好”“今天天气真不错”“今天天气真棒”只要意思合适，具体选哪个词通常都能接受。厂商可以利用这种选择余地，在生成过程里加入标记。

## KGW：动态红绿分组与概率偏置

### 固定分组的两个问题

一种直观方案是提前把 Token 分成红绿两组，生成时只允许使用绿组。例如，“不错”在绿组，“好”和“棒”在红组，模型就只能选择“今天天气真不错”。整篇文字都落在绿组，便成为这套方案的识别信号。

固定分组有两个问题：

1. 分组容易被推断。收集几千至几万条同一个模型的回复，统计哪些词始终不出现，就有机会推断红组；再人为加入一些红组词，可以破坏“全绿”的判别条件。
2. 红组词永远不能生成。大量表达被禁止，不仅限制模型发挥，也可能使句子越来越不自然。

### 每一步重新分组，允许红组继续出现

2023 年，马里兰大学研究者提出了一种更灵活的方案，作者称之为 KGW 算法，对应论文 *A Watermark for Large Language Models*。

在作者介绍的方案中，厂商保存一段秘密密钥。每生成一个 Token 之前，用前一个 Token 与密钥计算一个数，再据此重新划分红绿组。分组随前文变化，不再是一份固定词表。作者将这种变化带来的统计破解难度概括为“指数级增加”。

同时，方案不再禁止红组，而是给绿组 Token 加分、红组不加分。例如，“不错”被分进绿组后，概率可能从 30% 提高到 60%，而“好”从 50% 降到 30%。这组数字用于说明偏置如何改变选词。

允许红组出现，也能照顾选择空间很小的位置。“床前明月”后面几乎只能接“光”；即使“光”落入红组，其原本的概率优势仍可能压过绿组加分，从而尽量减轻水印对回复质量的影响。

### 检测整篇比例，不能只检查是否出现红组词

检测需要使用相同密钥，结合每一步的前一个 Token 重建分组，再判断当前 Token 属于红组还是绿组。

因为生成时只提高了绿组概率，没有完全排除红组，出现红组词并不能直接否定水印。检测关注的是整篇文字中绿组 Token 是否明显偏多。

作者以人工文本红绿各半为基线，举出一段 200 个 Token 的文字，其中至少 155 个落在绿组的例子。按给出的二项分布计算，这种情况的概率约为 $1.2\times10^{-15}$，也就是八百多万亿分之一；他将其与连续两次中双色球头奖的极低概率作类比，并据此解释为何强烈的绿组偏向可以成为水印证据。

样本量不足时，这种判断会变弱。只有 4 个 Token，按同样的红绿各半假设，全绿的概率就是 $1/16$，并不罕见。

### 改变概率仍可能损害表达

KGW 保留红组，并不等于完全不影响质量。“好”原本有 50% 的概率，加入偏置后降为 30%；天气描述里换成“不错”或许无妨，其他场合被挤掉的词却可能恰好最合适。

文学表达尤其重视这种差别。“僧推月下门”与“僧敲月下门”，仅一字之差，也值得反复推敲。概率被改动，意味着原本更合适的选择可能被替换。

## Aaronson 水印：用可重算的伪随机数参与采样

作者介绍，计算机科学家 Scott Aaronson 在 2022 年公开了一种不改变整体选择概率的水印思路，当时正为 OpenAI 研究水印。

理解这一思路，可以把普通采样想成区间抽签：将 0 到 1 按 Token 概率切分，0 到 0.5 对应“好”，0.5 到 0.8 对应“不错”，0.8 到 0.95 对应“棒”，余下部分对应其他选项。生成一个随机数，落在哪段就选哪个 Token。

在作者给出的简化说明中，用密钥和前一个 Token 计算的伪随机数，替换普通随机数。作者解释，伪随机数从宏观上仍均匀分布在 0 到 1，因此整体来看，各 Token 的选择概率不变。

检测时重算各步伪随机数，检查文字中的 Token 是否与该次选择吻合。在这套说明中，带水印的生成文本应逐步吻合，人工文本则只会偶然匹配其中一部分。

作者也指出其局限：伪随机数只由密钥和前一个 Token 决定，前一个 Token 相同就会得到同样的数，进而作出同样的选择；重复询问同一个问题，会得到相同回复。这是他从固定伪随机选择引出下一种方案的原因。

## SynthID-Text：保留随机抽样，再进行多轮淘汰

2024 年，Google DeepMind 在 *Nature* 发表了 SynthID-Text 相关研究。作者用一场小型淘汰赛解释其思路。

### 先独立抽样，再给选项分配硬币

在本例中，每次生成先按原概率独立抽样 8 次，例如得到 5 个“好”、2 个“不错”和 1 个“棒”，再让这些抽样结果两两淘汰，最终剩下一个作为输出。

每个待选 Token 会得到一枚虚拟硬币，标记为正面或反面。硬币由四项信息共同计算：密钥、前一个 Token、当前 Token，以及淘汰轮数。轮数从 1 开始；同一轮中，相同 Token 必须得到相同的正反面。

将 8 个抽样结果两两配对，按以下规则决定晋级：

- 正反面不同，正面晋级。
- 正反面相同，任选其中一个晋级。

第一轮后剩下 4 个，轮数加 1，重新计算硬币并继续配对，直到只剩一个 Token，成为模型真正输出。

作者强调，这一方案仍从原分布随机抽样，同时每种硬币正反面的机会各半，所以平均来看，各 Token 被选中的概率与不带水印时接近，并保留生成内容的随机性。

### 淘汰规则留下可检测的统计偏向

两枚硬币不同时正面晋级，两枚都是正面时仍是正面晋级，只有两枚都是反面，反面才有晋级机会。因此，最终输出更偏向正面。

检测时，利用相同规则重新计算文中各 Token 的硬币，再统计整篇的正反面比例。在作者的教学判别中，人工文本接近一半一半；若正面占据压倒性优势，则作为带水印生成文本的识别信号。

作者称，SynthID-Text 已开源，Gemini 在使用，Claude 后来也引入了它，并将其评价为当时最先进的 AI 水印技术之一。这些采用情况与评价均按作者的介绍保留。

## 改写能否去除水印？

对于这种分布在整篇文字中的统计标记，作者认为，只改少量文字不足以明显改变统计结果，因此不能仅靠修改几个字清除水印。

大量人工改写理论上可以削弱或去除标记，但改写达到一定程度后，文章是否仍应被视为 AI 生成，也变得难以划定。

另一种思路是使用不带水印的 AI 多次全文重写。作者同时提醒，这样做无法保证最终文章的质量。

## 内容的价值，是否取决于创作来源？

作者在调研中反复思考：分辨一段内容是否由 AI 生成，究竟有多重要？准确而深刻的文字，不会因为来自机器就失去价值；空洞而虚假的文字，也不会因为来自人手便变得珍贵。

但他也描述了一种从震撼到疲惫的变化：宫崎骏画风的自画像、模仿孙燕姿嗓音的流行歌，以及不断出现的 AI 动画，让线条、像素、文字与采样点反复填满屏幕。第一次令人震撼，到了“第 100 次”，却仍是相似的笔触、嗓音与线条。

作者用“宫崎骏用了一辈子才画出那样的画，现在一秒就能生成一万张”作对比，表达大量风格模仿与创作者本人之间的距离：每一张都像他，却没有一张是他。

在作者看来，使一种东西变得珍贵的，并不是它来自哪里，而是它能否在人心里停留。
