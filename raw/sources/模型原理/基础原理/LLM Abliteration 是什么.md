# llm abliteration是什么？

> 从残差流中的拒绝方向，理解无需重新训练的模型干预

“对不起，我不能回复这个问题，让我们来聊点别的吧。”作者以与 AI 对话时突然遭到拒绝的体验，引出 LLM Abliteration：在不进行微调或重新训练的前提下，去除模型的安全限制。

Abliteration 是网友将 ablate（消融）与 obliterate（抹掉）组合而成的词。理解这项技术，需要先看模型怎样在内部传递信息，再看拒绝行为能否对应到向量空间中的某个方向。

## 残差流：各模块共同写入的数据主干

用户输入的 Token 先经过 Embedding，转化为固定长度的向量。以 4096 维为例，这 4096 个数字承载模型对当前 Token 的内部表示，再经过各模块的变换，最终形成输出。

经典结构由注意力模块与多层感知机 MLP 反复组合。后续变化可以把注意力改为分组注意力，或把前馈神经网络改为 MoE；理解本篇原理时，重点在这些模块怎样连接。

真实模型并不是把前一个模块的输出直接当作后一个模块的全部输入，而是有一条持续累加的数据主干：

1. Embedding 生成的 4096 维向量进入注意力模块。
2. 注意力输出也是 4096 维向量，叠加到原向量上，形成新的向量。
3. 新向量进入 MLP，MLP 的输出再叠加进去。
4. 后续各层重复这一过程，注意力与 MLP 分别写入自己的信息。

因此，最后一层的结果可以直观理解为初始 Embedding 加上此前各层注意力与 MLP 的输出。这种相加的连接方式称为残差连接，贯穿各层的信息主干称为残差流。作者解释，这样连接是为了防止训练中的梯度消失问题。

残差流承载各模块逐步写入的信息，作者将它类比为人类的中枢神经：其中似乎隐藏着智能的关键机制，但经过十多年研究，人们仍未完全理解这些数字究竟怎样组织信息。

## 从词向量关系到拒绝方向

2013 年的 Word2Vec 研究展示过一种向量关系：国王的向量减去男人的向量，再加上女人的向量，结果约等于女王的向量。

这一现象的启发是：性别概念似乎在向量空间中对应着一个固定方向。沿某个方向移动，向量中表达女性的含义增加；沿相反方向移动，表达男性的含义增加。那么，拒绝行为是否也与某个方向有关？

2024 年，Arditi 等人发表了 *Refusal in Language Models Is Mediated by a Single Direction*。作者介绍，研究者测试了 Llama、Qwen、Gemma 等 13 个开源大模型，发现这些模型的残差流中各自存在一个与拒绝有关的方向。

在研究所测试的模型中，抹除这个方向的信息，模型不再拒绝有害请求；反过来，向残差流中加入这个方向，模型连无害问题也会拒绝。例如，询问怎样做西红柿炒鸡蛋，也可能得到道歉和拒绝。

这里的“由单一方向传导”，指的正是删除与添加方向会改变拒绝行为的实验观察。

## 用两组提示词提取方向

### 在回答开始前记录逐层残差

研究者准备有害与无害两组提示词，每组 128 个问题。有害组包含模型默认会拒绝的危险请求，例如询问怎样制作炸弹；无害组是模型默认不会拒绝的普通问题。

将提示词逐条输入模型，记录完整提示最后一个 Token 进入模型后，各层残差流的数值。

这个位置并不是用户问题末尾的问号。模型通常先按聊天格式加入角色与边界标记，例如把问题组织成用户内容，再接上 `assistant` 所代表的回答起始位置。模型继续生成的文本，才是对用户的回答。

不同开源模型采用的聊天标记不同，有些会在 `assistant` 前后加入多个标记。研究者对几个相关位置分别做了处理；本篇以最后的回答起始位置作简化说明，不把它当作所有模型固定使用的同一个 Token。

假设模型有 32 层、残差维度为 4096，每个问题便得到 32 个 4096 维数组。选择回答开始前的位置，是因为模型刚读完问题、即将生成回复；作者认为，是否拒绝的信息已经蕴含在这些逐层残差中。

### 逐层求平均，再比较两组差异

有害组的 128 个问题一共得到 $128\times32$ 个残差向量。将它们按层分组并求平均，得到 32 个有害组平均向量。无害组用相同方法处理，也得到 32 个平均向量。

逐层用有害组平均向量减去无害组平均向量，便得到 32 个差向量。研究者推测，能够影响拒绝行为的方向就在这些差向量中。

这套方法的直观解释是：两组问题包含不同主题，研究者期待求平均后，各个问题特有的信息相互抵消、变得模糊，共同成分则被保留下来。有害组共有“这是一个请求”与拒绝，无害组共有“这是一个请求”与允许；两组相减后，请求本身的共同成分被消去，留下拒绝与允许之间的差异。

这是研究者寻找方向的思路，最终仍需要实验检验。

## 用干预与分布变化筛选方向

### 删除投影，观察拒绝是否消失

对每个待检验方向，将有害问题输入模型，在每一层、每一个 Token 的残差中减去沿该方向的投影，使这一方向上的分量变成 0，再观察模型是否仍拒绝。

这里有一个明确的实验假设：同一个模型中，所有 Token、所有层的残差共享同一拒绝方向。对各层、各位置施加同一方向的干预，就是为了测试这个假设是否成立。

逐个检验 32 个方向后，再挑出效果最好的一个。

### 既检查删除，也检查反向添加

研究者不必等模型生成完整回答，而是查看第一个生成 Token 的概率。如果 “I'm sorry…”、“As an AI…” 等拒绝式表达的开头概率很高，就说明模型仍倾向拒绝。这样，一个问题只需要完成用于检查下一 Token 分布的前向计算。

还需要反向验证：将该方向加到无害问题的残差中，模型应开始拒绝。删除后减少拒绝、添加后诱发拒绝，两种干预共同检验这个方向的作用。

### 用 KL 散度排除破坏正常输出的方向

不再拒绝不一定意味着找到了合适的方向。某个方向被删除后，模型也可能丧失正常回答能力，开始胡言乱语。

为排除这种情况，研究者对同一个无害问题，分别运行原模型与删除方向后的模型，比较下一 Token 的概率分布。两种分布的差异用 KL 散度量化；差异太大的方向直接淘汰。

因此，筛选同时检查三个方面：删除方向后是否仍拒绝、添加方向后是否产生拒绝，以及正常问题的输出分布是否发生过大变化。经过比较，才选出用于后续处理的拒绝方向。

## 从动态干预到直接修改权重

运行时不断删除残差中的方向分量，可以改变拒绝行为，但需要动态干预，与普通模型的加载和运行方式不同。

作者进一步解释：向残差流写入信息的地方，包括初始 Embedding，以及每层注意力与 MLP 的相关矩阵变换。与其在运行时逐次清除方向，也可以直接修改这些写入矩阵。

将拒绝方向归一化为长度 1 的 $\hat r$，原权重矩阵记为 $W$，修改后的矩阵为：

$$
W'=W-\hat r\hat r^{T}W
$$

按这一处理方式，每个相关矩阵写入残差流的结果，在拒绝方向上的分量都变为 0。作者将其解释为与运行时动态删除该方向在数学上等效，从而得到经过 Abliteration 处理的模型，而无需通过微调或重新训练来完成这次修改。

Hugging Face 上可以找到带有 `abliterated` 等标记的处理后模型。作者还介绍了专门执行相关处理的 `abliterator` 库。

## 概念是否都能表现为方向？

拒绝方向之外，作者还提到有关真假与讨好行为的方向研究，并由此提出一种可能性：人们感受到的 AI 脾气与性格，拆开后也许与若干内部方向有关。

这仍是一种探索性的联想。科学常从复杂现象中寻找更简洁的规律：电与磁被统一到方程中，多样的化学反应可以从原子与电子的排列组合理解。看似千头万绪的 AI，底层是否也可能遵循少数简单规则，例如某些概念对应某些方向，仍值得继续研究。
