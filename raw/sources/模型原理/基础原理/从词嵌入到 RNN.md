# 从词嵌入到 RNN

给几个字，要生成下一个字；给一句话，要判断每个词的褒贬。若把这些做成神经网络，文字必须先变成计算机能识别的数字。这个过程叫编码。

## 一个数字太低，独热又太高

一种极端是每个词只用一个数字标识。例子是 1 代表我，2 代表你，3568 代表地球。词表有多大，标识的范围就要有多大。缺点是维度太低，相当于一维向量。标识本身对理解语言没有意义，也不能灵活衡量词和词的相关性。

另一种极端是准备一个非常大的向量，每个词只有一个位置是 1，其余都是 0。这叫 one-hot，独热编码。缺点是维度太高，而且非常稀疏。假如词表有 10 万个词，向量就是 10 万维；这些向量彼此正交，词和词之间仍然找不到相关性。把每个位置看成一个特征，特征就只是死板的是或否。画面用「他、开心、我、就、生气」演示，左侧的特征问句包括是不是好、是不是他、是不是我、是不是开心、是不是饿、是不是生气、是不是就。

维度太高不好，太低也不好。不高不低的做法叫词嵌入。这样得到的词向量维度居中，每个位置仍可以理解为一个特征，但特征是训练出来的，不是人定的，人可能完全看不懂它是什么。词和词在语义上的相关性，可以用两个向量的点积或余弦相似度来算，自然语言里的联系就变成了可以计算的量。

一个训练好的词嵌入矩阵，可能会使桌子减去椅子等于鼠标减去键盘。画面上的向量是：

- 桌子：$0.12, 0, 0, 0.43, 0, 0, 0.4$
- 椅子：$0.11, 0, 0, 0.23, 0, 0, 0.4$
- 鼠标：$0.24, 0, 0, 0.65, 0, 0, 0.5$
- 键盘：$0.23, 0, 0, 0.45, 0, 0, 0.5$

所有词向量组成一个大矩阵，叫嵌入矩阵。纵向是词向量维度，横向是词表大小，每一列是一个词向量。它不是人给每个词手工赋值，而是用深度学习训练出来的。比较经典的方式是 word2vec，这一节不展开。画面上的小演示写着 `https://ronxin.github.io/wevi/`，词包括 apple、drink、eat、juice、milk、orange、rice、water。有了这张矩阵，每个可能的词都能查到对应的词向量。

这些词向量维度很高，所在空间的维度也很高。这个空间叫潜空间。人好理解二维，三维也还行，再高就想象不出来。高维潜空间里的相对位置可以用点积或余弦相似度算出来；也可以把潜空间降维，投影到二维或三维坐标系里看词语距离，哪怕不那么准确。

## 整句铺进输入层，顺序就没了

此时每个词都能变成向量，送到输入端的神经元。回到判断一句话里每个词的褒贬。「他、开心、我、就、生气」是 5 个词，词嵌入把每个词变成 300 维，输入端一共要 1500 个神经元。这样做可以，但有两个问题。输入层太大，而且会随句子里的词数变化，长度不确定。另一个问题是没有先后顺序，只是把词生硬地铺成一个大向量送进去。这和把一张图片的全部像素铺开再送进输入层是同一个道理：神经元变多，又不能很好地抽出特征和关联。

图像里，CNN 用卷积提取特征。自然语言要同时保留词的先后，并降低输入层的规模。做法仍用经典神经网络，但一次只输入一个词，输出这个词是褒义还是贬义。式子里的字母表示矩阵。第二个词走同一个网络。用尖括号标记第几个词，顺序就有了，例如 $X^{<1>}$ 是「他」，$X^{<2>}$ 是「开心」。问题是第二个词的计算完全没有用到第一个词。

## 隐藏状态把前一个词带下去

让第一个词先做非线性变换，结果不要直接当输出，而是先得到隐藏状态 $h^{<1>}$，再做一次非线性变换得到 $Y^{<1>}$。$h^{<1>}$ 再和第二个词 $X^{<2>}$ 一起运算。第二个词同样先得到 $h^{<2>}$，然后继续往后传。前面词的信息就这样传到句子的最后一个词，整句话都被带进来。

权重要分开。$W_{xh}$ 专门乘词向量，$W_{hh}$ 专门乘隐藏状态，$W_{hy}$ 用来算输出。偏置也要分开，画面上是 $b_h$ 和 $b_y$。把图收成一个循环：输入 $X$ 经过 $W_{xh}$ 进入 $h$，$h$ 经过 $W_{hy}$ 得到 $Y$，$h$ 自己再经 $W_{hh}$ 绕回来。这就是循环神经网络，RNN。

它因此能处理词的先后，用来判断一句话里各个词的褒贬，也可以给定一句话不断生成下一个字，以及做翻译和其他自然语言处理。

把矩阵展开：第一个词 $X^{<1>}$ 与 $W_{xh}$ 相乘，得到准备往后传的 $h^{<1>}$；$h^{<1>}$ 再与 $W_{hy}$ 相乘，得到 $Y^{<1>}$。算第二个词时，同样要乘 $W_{xh}$，还要把第一个词的隐藏状态拼进输入，权重里再增加 $W_{hh}$，得到 $h^{<2>}$。后面的时间步相同。和经典神经网络相比，就是多了前一时刻的隐藏状态：

$$
h^{<t>}=g_1(W_{xh}X^{<t>}+W_{hh}h^{<t-1>}+b_h)
$$

$$
y^{<t>}=g_2(W_{hy}h^{<t>}+b_y)
$$

不同的词用不同的时间步 $t$ 表示。

## 按时间步传递，远距离仍然会丢

RNN 还有两个严重问题。信息会随着时间步增多而逐渐丢失，无法捕捉长期依赖；有的句子恰恰是离得很远的地方起了关键作用。RNN 还必须按顺序处理，每个时间步依赖上一个时间步隐藏状态的计算结果。

GRU 和 LSTM 改进了传统 RNN，但仍然是让信息按时间步一点一点传递，只能缓解，不能根治。若要彻底抛弃这种顺序计算，一次把全部信息收进来，作者给出的方案是 Transformer。这一节没有展开它。
