> 模型架构／注意力机制独立专题

“我用毒毒毒蛇”把同一个“毒”字连续放在一句话里，却仍然可以被理解：第一个“毒”位于介词“用”之后，表示所使用的毒物；第二个“毒”表示施加毒害的动作；第三个“毒”修饰“蛇”。字形没有变化，每个位置承担的语法与语义作用却不同。

理解语言时，注意力会随上下文改变焦点。注意力机制试图让模型也能根据当前词与其他词的关系，动态形成上下文表示。

## Embedding 是注意力的输入

文本进入 Transformer 后，首先被转换为 Embedding。每个词元不再只是一个符号，而是由一组数字构成的向量。

为了说明这种向量，资料把“毒”类比为“危险 100 分、柯南 50 分、中文 100 分、动词 70 分、名词 90 分、形容词 80 分”。这些名称和分数只是教学示意。真实模型中的向量维度由训练自动形成，人类通常无法为每一维指定或确认清晰含义。

资料称，早期 GPT-2 的向量可以包含 1600 个数字，DeepSeek 为 7168 个，并推测流行商业模型可能已经超过一万维。维度越高，直接比较长文本中所有词元的关系，计算成本越大；混合在同一向量中的语法、语义和其他特征也不便用单一视角解释。

## 多个头学习不同的关系投影

多头注意力把同一组输入并行送入多个 Attention Head。每个头使用不同的线性投影，因此可以学习不同的关系模式。为便于理解，可以把一个头想象成主要关注语法，另一个头主要关注故事关联，还有一个头关注感受。

这些关注点同样只是解释设计初衷的类比。训练完成后，某个头究竟提取了语法、人物关系，还是多种特征混合形成的新表示，通常不能仅凭投影矩阵直接确定。

## K：描述词元具有什么特征

资料先把原始 Embedding 输入线性层，得到一张“语法表”。这张表记录每个词元在动词、名词和形容词等示意维度上的分数，对应注意力公式中的 Key 矩阵 $K$。

Key 可以理解为词元向其他词元提供的特征。这里把它称为“语法表”，只是为了让矩阵投影更直观，并不表示真实 Key 向量中的维度就是可读的语法标签。

## Q：描述当前词元需要寻找什么

同一份原始 Embedding 经过另一组线性变换，得到“需求表”，对应 Query 矩阵 $Q$。它表示每个词元在当前注意力头中要寻找什么特征。

例如，“蛇”是名词，常由形容词修饰。示例因此把它对形容词的需求设为较高分，对动词和名词的需求设为较低分；某些关系还可以使用负数，表示不倾向建立关联。

Query 与 Key 使用不同的投影矩阵。一个描述“我在寻找什么”，另一个描述“我具有什么”，两者相乘后才能得到词元之间的关联分数。

## QKᵀ：计算关联分数

关联分数来自 Query 与 Key 的向量乘法。资料中的“蛇”需求向量为 $(20, 5, 100)$，“毒”的示意 Key 为 $(60, 70, 80)$，点积结果为：

$$
20 \times 60 + 5 \times 70 + 100 \times 80 = 9550
$$

高分意味着当前 Query 与相应 Key 在该投影视角下更匹配。把所有词元两两计算一次，在工程上就是矩阵乘法 $QK^T$，结果形成关联度矩阵。

## Mask：不让生成模型看到未来

双向编码模型可以直接使用完整的关联度矩阵。GPT、Gemini 等自回归生成模型还需要使用因果 Mask：当模型处理当前位置时，只允许关注当前位置及之前的词元，不能读取尚未生成的后续内容。

实现时，关联度矩阵中代表未来位置的分数被设为负无穷。经过 Softmax 后，这些位置的权重变成 0，从而不会参与当前词元的后续计算。

## 缩放与 Softmax：把分数变成权重

点积可能随着 Key 的维度增大而产生过大的数值，因此在 Softmax 前还要除以 $\sqrt{d_k}$。这里的 $d_k$ 是 Key 的维度。完整的权重计算为：

$$
\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)
$$

Softmax 按行把分数转换为权重，每一行之和为 100%。高分位置获得较大权重，低分位置获得较小权重，被因果 Mask 设为负无穷的位置则获得 0 权重。

资料强调，演示中为了便于计算使用了几十、几百乃至几千的分数；实际投影值通常是较小的正负小数。演示数字用于解释计算关系，不代表真实模型中的数值范围或可解释标签。

## V：提供要汇总的内容

第三组线性投影把原始 Embedding 转换为 Value 矩阵 $V$。资料把它称为“内容矩阵”：如果当前注意力头关注语法，可以将其类比为保留与语法相关的内容并降低维度。

关联度权重与 $V$ 相乘，相当于按照每个词元的重要程度对内容向量加权求和。示例中，“蛇”对“我”的权重为 10%，对“用”为 0%，对三个“毒”各为 25%，对自身为 15%。新向量因而混合了这些位置的信息，既包含“蛇”本身，也包含它在上下文中的关系。

同样地，“内容”仍是教学类比。真实 Value 向量保存了什么，不能直接由人类为每一维命名。

## 从单头到多头

一个 Attention Head 的完整计算可以写为：

$$
\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

多头注意力并行执行多组独立的 $Q$、$K$、$V$ 投影和 Attention 计算，再把各个头的结果按词元拼接。每个头可以形成不同的上下文视角，拼接后的表示同时包含多组关系信息。

Transformer 会让这种上下文表示继续进入后续层，重复执行多次注意力与变换。经过多层计算后，内部向量已经难以用人类直觉逐维解释，但每一步仍由明确的矩阵运算组成。

## 总结

多头注意力的核心链路是：Embedding 提供词元的初始表示；Query 表达当前位置要寻找什么；Key 表达各位置能够提供什么；$QK^T$ 计算关联分数；因果 Mask 屏蔽未来位置；缩放与 Softmax 把分数转换为权重；Value 提供被加权汇总的内容；多个头并行学习不同的关系投影。

资料最后将这种体验概括为科学的吸引力：公式本身可以逐行写出，层层叠加后的内部表示却仍有大量无法直观解释之处。正因为尚未完全理解，模型机制才值得继续探索。
