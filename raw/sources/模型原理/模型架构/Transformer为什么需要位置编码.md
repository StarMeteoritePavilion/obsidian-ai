# Transformer为什么需要位置编码

“狗咬人”和“人咬狗”包含相同的词，却表达相反的关系。最朴素的 Attention 计算本身没有使用 Token 的位置，因此需要把“第几个 Token”编码进输入向量。

## Attention 本身为什么不区分顺序

Attention 的计算为：

$$
\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

以“张三打李四，谁疼”和“李四打张三，谁疼”为例。进入 Decode 阶段后，当前 Token 都是“疼”。它的 Query 分别与前面各 Token 的 Key 做点积，经 Softmax 得到权重，再对相应的 Value 加权求和。

交换“张三”和“李四”的位置，只会让 Key 的分数项与对应的 Value 按相同方式换序。每个 Value 对应的权重没有改变，而加权求和不受各项排列顺序影响，因此两句话会得到相同的结果向量。输出相同时，自回归模型也就无法仅凭这次计算区分究竟是谁疼。

因此，没有额外位置信息时，句子在 Attention 中更接近 Token 集合，而不是有先后关系的 Token 序列。

## 三种直接编码方案的取舍

位置编码需要与 Token Embedding 结合，让模型在语义之外获得顺序信息。可以先从三种直接方案理解它需要满足的条件。

### 直接加入绝对位置

假设序列共有 64 个 Token，“李四”位于第 24 个位置，每个 Token 是一个 $d$ 维 Embedding。最直接的方案，是给这个向量的每一维都加上 24。

这种做法保留了绝对位置，却会让位置号比原向量中的小数大一两个数量级。位置值加入后，原有语义容易被淹没。

### 按序列长度归一化

另一种方案是用位置除以序列总长度 $L$，把编码限制在 0 到 1 之间。第 24 个位置在长度为 64 的序列中编码为：

$$
\frac{24}{64}=0.375
$$

但在长度为 1000 的序列中，同一位置会变成：

$$
\frac{24}{1000}=0.024
$$

编码因此依赖序列总长度，同一绝对位置没有稳定表示。

### 使用二进制

位置 24 可以写成六位二进制数：

$$
24=011000_{(2)}
$$

每一位都只取 0 或 1，值域固定；无论序列多长，位置 24 的编码都不改变。不同位还具有不同变化周期：最低位每经过一个位置翻转一次，随后各位每 2、4、8、16 个位置翻转一次。

二进制编码的问题是跳变。位置 23 的编码是 `010111`，位置 24 则是 `011000`，相邻一步便有四位同时改变。资料把这种不连续性与梯度下降所需的平滑变化对比：理想情况下，位置只移动一点，编码也应连续移动，模型才能沿梯度学习变化方向。

## 正弦位置编码

《Attention Is All You Need》采用正弦与余弦函数构造位置编码。编码维度两两一组，偶数维和紧随其后的奇数维分别定义为：

$$
\operatorname{PE}_{(pos,2i)}=\sin\left(\frac{pos}{10000^{2i/d}}\right)
$$

$$
\operatorname{PE}_{(pos,2i+1)}=\cos\left(\frac{pos}{10000^{2i/d}}\right)
$$

其中，$pos$ 是 Token 的位置，$i$ 是第几组，$d$ 是向量维数，10000 是固定底数。同一组使用相同自变量，区别只在于一个取正弦，另一个取余弦。

这种结构与二进制编码的多尺度变化相似：低维组变化较快，越往高维变化越慢。区别在于方波被换成正弦波，跳变也随之变为连续变化。正弦与余弦的值天然位于 $[-1,1]$，公式又不包含序列总长度 $L$，因此编码只由位置决定。

## 波长为什么形成等比序列

基础函数 $y=\sin x$ 的波长为 $2\pi$；若函数变为 $y=\sin(x/2)$，波长便拉长为 $4\pi$。分母扩大多少倍，波长也相应扩大多少倍。

第 $i$ 组正弦位置编码的波长因此为：

$$
\lambda_i=2\pi\cdot10000^{2i/d}
$$

以 $d=8$ 为例，共有四组编码。$i=0$ 时指数为 0，波长是 $2\pi$；$i=1$ 时指数为 0.25，$10000^{0.25}=10$，波长是 $20\pi$。其余各组继续按 10 倍增长。

一般情况下，随着 $i$ 增大，最高维组的波长逐渐接近 $2\pi\times10000$，约为六万多个 Token。资料据此解释底数 10000：不同维度提供从短到长的变化周期，组合起来覆盖普通上下文中的位置差异。把底数改成十万或一百万可以继续拉长最高维周期，但资料认为普通文本理解很少需要读取十万个 Token 以前的信息，因此没有太多必要。

## 把每组编码理解为钟表指针

令第 $i$ 组的角频率为：

$$
\omega_i=\frac{1}{10000^{2i/d}}
$$

该组编码便可以写成 $\sin(\omega_i pos)$ 与 $\cos(\omega_i pos)$。正弦和余弦共同表示单位圆上的一个点，也可以理解为一根钟表指针。位置 $pos$ 每增加 1，指针就转过 $\omega_i$；$i$ 越大，$\omega_i$ 越小，指针转得越慢。

一根指针无法精确表示时间，但秒针、分针和时针合在一起便能确定时间。正弦位置编码采用相同思路：每两个维度表示一根不同转速的指针，所有快慢指针的方向合在一起表示位置。波长在这种解释下，也就是指针完成一圈所需的位置跨度。
