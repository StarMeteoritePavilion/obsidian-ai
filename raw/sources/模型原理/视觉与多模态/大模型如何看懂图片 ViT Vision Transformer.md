# Vision Transformer 如何把图像转换为模型可处理的表示

大语言模型主要通过处理文本的词元（Token）来理解和生成自然语言，而多模态模型则需要将图像和文字都转换为可以共同计算的数字表示。为了实现这一目标，视觉模型通过特定的架构将图像转换为特征序列，其中 Vision Transformer（ViT）是最具代表性的方法。本篇以 ViT 为例，介绍图像处理的基本链路。

## 像素输入

图像的最基础构成是像素。一张分辨率为 $224\times224$ 的图像包含 50,176 个像素。对于彩色图像，每个像素由红、绿、蓝（RGB）三个通道表示，这意味着整张图像包含 150,528 个数字（标量）。

如果将所有像素直接展平送入模型，不仅会丢失显式二维局部结构，序列或全连接计算的成本也会随输入尺寸增长。对高分辨率、语义复杂的图像，需要先组织局部区域，再学习区域之间的关系。

## Patchify（图块化）

为了降低计算复杂度和提取有意义的特征，ViT 将整张图像切分为不重叠的小图块（Patch）。

以 $224\times224$ 的图像为例，若将其划分为 $16\times16$ 的图块，每行和每列各有 14 个，整张图像会被切分为 $14\times14=196$ 个图块。每个彩色图块包含 $16\times16\times3=768$ 个数字。

此时，每个图块代表了图像局部的像素组合。自然语言可以用来辅助理解这种局部特征（例如，某个图块可能包含“圆形、透亮、中间有黑点”的视觉特征，另一个图块则包含“黄色、毛茸茸”的特征），但这只是为了说明局部与全局关系的类比，模型实际输出和处理的仍然是代表这些视觉特征的高维向量，而非词义标签。仅凭单个图块的局部信息，往往无法判断完整对象的身份。

## 线性投影与位置编码

图块化之后，模型还需要将它们转化为更适合 Transformer 处理的格式：

1. **线性投影（Linear Projection）**：将每个包含 768 个标量的图块展平，并通过一个线性层（可以理解为一个矩阵乘法），将其投影为一个固定维度的向量（Embedding）。
2. **位置编码（Position Embedding）**：因为序列输入会丢失图块在原始 2D 图像中的空间位置，ViT 会为每个图块向量加上一个位置编码。因此，模型所感知的图块空间顺序不仅依赖于输入时的矩阵行顺序，更依赖于位置编码所提供的空间信息。
3. **Class Token（类别词元）**：在原始 ViT 的设计中，序列最前端还会拼接一个特殊的 Class Token。它的作用是在后续的计算中汇总全局图像的信息，从而用于最终的图像分类等任务。

## Transformer Encoder

加上位置编码的向量序列（包含 Class Token 与 196 个图块向量）会送入 **Transformer Encoder** 进行处理。Encoder 由多个包含多头自注意力机制（Self-Attention）和前馈神经网络（FFN）的 Block 组成。

在图像处理中使用 Transformer Encoder 的原因，一方面是图像各部分的依赖关系是双向的，不存在类似文本生成的时序因果限制。在自注意力机制中，代表局部视觉特征的图块（例如“眼球”形状）可以与全图其他图块（如“毛发”、“尾巴”特征）建立关联，从而在模型的计算中明确其整体概念。另一方面，图像分类或图像表征等任务的非自回归（Non-autoregressive）性质，也需要模型利用无掩码的双向上下文来生成完整的图像特征。经过 Encoder 的计算，输出矩阵的每一行虽然仍然对应初始的一个图块或 Token，但其向量已经综合了全局的图像上下文信息。

## 多模态接口与语言模型

在多模态语言模型中，视觉编码器的作用是将图像转换为视觉特征，但其输出并不能与文本 Token 无条件地直接拼接。

首先，多模态模型未必直接采用原始 ViT 中的 Class Token 作为全局视觉输出。根据架构的不同，模型可能会提取所有图块的序列特征，或者对其进行池化（Pooling）。

其次，视觉编码器输出的特征通常还需要经过一个**多模态接口**，例如一个简单的线性投影器（Projector）、Q-Former 或交叉注意力（Cross-Attention）层，将视觉特征的维度与表征映射对齐到大语言模型的语义空间中。

经过多模态接口对齐后，这些对齐的特征才能与用户的文本输入一起送入语言模型。语言模型进而结合视觉特征与语言理解能力，生成针对图像的回答。

最后需要说明的是，多模态语言模型的视觉编码器可能是 ViT 及其变体，也可能采用完全不同的架构（如 CNN 或混合架构），以上流程仅代表最普遍的 ViT 图像接入链路，而非所有多模态模型的统一实现。
