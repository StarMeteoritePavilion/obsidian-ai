> 大模型后训练独立专题

Agentic Reinforcement Learning（ARL）训练可能在前期持续改善后突然崩塌：成功率归零、输出格式失控，换一个随机种子又得到完全不同的结果。这不是单轮推理训练中的局部波动，而是多轮 Agent 任务面临的系统性稳定性问题。

多轮 Agent 往往要连续执行几十步决策，直到任务结束才获得结果奖励。奖励稀疏、策略更新造成的数据过期，以及早期错误经环境状态逐步放大，三种压力会同时作用于训练。ARLArena 试图先建立统一、可复现的训练环境，再从策略梯度的设计维度定位崩塌来源。

## ARLArena 拆解的四个维度

ARLArena 完成了四项工作：建立标准化训练测试台；把策略梯度拆成损失聚合、重要性采样裁剪、优势函数设计和动态采样四个维度；系统比较这些维度对性能与稳定性的影响；在实验结果之上提出 SAMPO。

这套分析强调，Agentic RL 的稳定性不是由单一技巧决定。各个设计维度存在交互效应，分别有效的组件直接叠加后不一定仍然有效。

## 强化学习之前先限定行为范围

模型在没有形成基本交互规范时直接接受稀疏奖励，打分本身很难提供稳定的学习方向。论文采用行为克隆初始化：先用高质量交互轨迹进行监督微调，让模型进入合理的行为范围，再开始强化学习。

训练早期还加入格式惩罚和 KL 正则化，限制模型过快偏离初始策略。这些措施构成后续策略优化的基础，但稳定性的关键仍在重要性采样裁剪。

## 容忍型裁剪为何会积累危险梯度

策略更新后，采集数据所对应的旧策略与当前策略产生偏差。重要性采样比率用于校正这种差异；当某个 Token 的比率过于极端时，需要裁剪其影响，防止一次更新把策略推向异常区域。

SAPO 和 CISPO 使用容忍型裁剪。重要性采样比率超出范围后，它们不直接截断对应 Token 的作用，而是以软化方式继续保留梯度信号。这样做可以避免丢弃信息，却也会让本应停止参与更新的序列继续影响策略。

论文的统计分析发现，训练崩塌前会大量出现“负优势、低重要性采样比率”的序列。这类序列对应当前策略已经降低其发生概率、且任务结果也较差的行为。容忍型裁剪仍让它们持续提供梯度，危险信号逐步累积，最终可能造成梯度爆炸和训练崩塌。

## 从 Token 级判断改为序列级裁剪

常规裁剪逐个判断 Token。一条长轨迹中只要出现少数极端 Token，就可能显著影响整条轨迹的梯度。

序列级裁剪先对一条轨迹中全部 Token 的重要性采样比率取几何平均，再用这个序列级数值决定整条轨迹是否参与更新。单个极端 Token 因而不能独自控制整条轨迹，负优势且低比率的危险序列也可以整体排除。论文实验把序列级裁剪列为对训练稳定性影响最显著的单项设计。

## 用步骤级优势缓解信用分配

只为整条轨迹提供一个总分，会让轨迹内所有动作共享同一奖励，模型无法分辨哪一步决定了最终成败。GiGPO 引入步骤级优势：当不同轨迹在某一步到达相同环境状态时，横向比较此处的不同动作，为该步骤计算相对优势。

步骤级优势把信用分配从轨迹整体细化到关键决策，对稀疏结果奖励形成补充。它不能消除长程任务的全部归因困难，但能提供比单一轨迹总分更丰富的训练信号。

## 动态采样依赖优势设计

动态采样会过滤同一组中全部成功或全部失败的轨迹，因为组内没有相对差异时，优势信号为零，继续训练只会消耗算力。

不过，动态过滤与 GRPO 直接结合后，实验效果反而下降。训练早期的大量失败样本仍携带格式学习信号；过早过滤这些样本，模型便失去了学习输出规范的机会。GiGPO 提供更细粒度、更多样的优势信号，格式学习不再完全依赖这些失败轨迹，动态过滤才可以稳定发挥作用。

这项结果说明，动态采样不能脱离优势设计单独判断。SAMPO 将序列级裁剪、细粒度步骤级优势和动态采样组合起来，三部分共同构成稳定训练方案。

## 四项任务的实验结果

ARLArena 的对比表以 Qwen3-4B 的 SFT 版本为底座，覆盖四类多轮任务：

- ALFWorld：文字形式的家庭环境规划任务。
- WebShop：模拟网络购物任务。
- Sokoban：以视觉输入完成推箱子任务。
- TIR Math：使用 Python 工具辅助求解 AIME 数学竞赛题。

SAMPO 在 ALFWorld 上的成功率为 92.72%，GRPO 基线为 62.36%，相差 30.36 个百分点。在 Sokoban 上，CISPO 和 SAPO 的成功率分别为 26.02% 和 30.25%，GRPO 为 83.90%，SAMPO 为 88.86%。论文汇总表将 SAMPO 的平均结果记为 60.21，并标注平均提升 25.2%；但 SAMPO 行在 TIR Math 两列均为缺省值。资料旁白称 SAMPO“在四个任务上”全面超过对比方法，这一范围与论文官方表格不一致，不能据此补出 TIR Math 结果。已列出的结果只属于 Qwen3-4B 和论文训练设置，不能直接外推到其他环境。

资料还比较了同一 ALFWorld 任务上的闭源模型系统：GPT-5.2 单 Agent 成功率为 51.56%，o3 Multi-Agent 为 56.25%，专项训练的 Qwen3-4B SAMPO 为 92.72%。闭源模型没有针对该环境进行相同的专项训练，因此这不是同等训练条件下的模型能力比较。它能说明环境对齐的稳定强化学习在特定任务上具有明显价值，不能据此认定 4B 模型普遍超过 GPT-5.2 或 o3。

## 结论与开放问题

ARLArena 把 Agentic RL 的训练稳定性还原为相互作用的策略梯度设计问题。资料将崩塌的主要来源归于负优势、低重要性采样比率的序列持续腐蚀梯度信号，并以序列级裁剪、步骤级优势和动态采样共同缓解这一问题。

SAMPO 在论文表格给出结果的受控任务中实现稳定训练并超过对应对比方法，但真实开放式 Web Agent 的状态空间、工具噪声和任务长度更复杂。相同训练配方能否保持稳定，仍是需要独立实验回答的问题。
