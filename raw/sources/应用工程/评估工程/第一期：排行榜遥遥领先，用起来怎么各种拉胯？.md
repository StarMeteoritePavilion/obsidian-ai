> 评估工程系列 第一期

大模型在 ARC、MMLU、TruthfulQA、HellaSwag、GSM8K 等通用排行榜上表现靠前，不代表它能直接处理业务中的真实问题。客服机器人面对的是用户在具体情境中发来的消息，而不是标准选择题。

评估的本质不是单纯打分，而是把模型的通用能力翻译成业务中的“到底能不能用”。这一期从黄金数据集、三种评分方式和一条从 Workbench 到 CI/CD 的实施路径出发，建立评估工程的整体框架。

## 评估体系的四层结构

完整评估体系由四层组成：

1. **黄金数据集**：保存真实输入和领域专家给出的黄金答案，是整个体系的基础。
2. **三个评分引擎**：使用人工、代码或 LLM 对模型输出评分。
3. **四个价值出口**：用评估结果改进 Prompt、选择模型、比较版本并降低成本。
4. **生产管道**：从 Workbench 中的快速原型逐步走向 CI/CD 自动门禁。

这四层把一次主观体验转成可以复现的质量闭环：先准备业务数据，再选择评分方式，随后用结果指导决策，最后把评估嵌入持续交付流程。

## Benchmark 不是业务答案

通用 Benchmark 回答的是模型在统一考试中表现怎样，业务评估回答的是这套模型在自己的数据和场景里是否可用。两者测试的对象不同，不能用前者替代后者。

一套最小可用的业务评估由四部分组成：

1. **输入样例**：来自用户真正会问的问题，不是凭空设计的理想问题。
2. **黄金答案**：由真正理解业务的领域专家编写，不能让模型自产自销。
3. **模型输出**：记录 Prompt 与模型实际生成的结果。
4. **评分**：把模型输出和黄金答案放在一起比较。

缺少任何一块，评估都无法可靠回答“这套系统在业务里到底行不行”。

## 三把评分尺子

### 人工裁判

领域专家逐条查看结果，可以使用一至五分的 Likert 评分，也可以对 A、B 两个结果进行成对比较。

人工裁判能够理解模糊、主观和依赖上下文的判断，是资料所说的金标准；代价是昂贵、缓慢，难以规模化。多名专家共同评审数百条数据时，预算和时间会迅速成为瓶颈。

### 代码扫描仪

用 Python 编写确定性规则，通过精确字符串、关键词或正则表达式检查输出。

代码评分速度最快、成本最低，适合存在标准答案的任务；遇到语义模糊、表达多样或强上下文任务时，它无法覆盖全部有效答案。

### LLM 裁判

让另一个能力更强的模型依据评分标准检查输出。它比人工快，也比代码规则更能理解语义，处于前两者之间。

LLM 裁判需要经过精心设计和校准的评分标准，否则模型偏见会直接进入评估结果。三把尺子并非互斥，真实业务通常把确定性规则、LLM 判断和人工复核组合使用。

## 黄金数据至少覆盖 100 对

资料把 100 对测试数据作为能够指导决策的最低规模：30 至 50 对只能提供类似抛硬币的初步信号，少于 100 对时结论不稳定，达到 100 对以上才进入可用于决策的范围。

数量本身不够，数据分布还要真实。测试集需要同时覆盖：

- 真实用户的高频问题。
- 容易失败的边缘情况。
- 一年中偶尔出现、但不能忽略的长尾输入。

黄金答案必须由领域专家标注。用垃圾输入或模型自行生成的答案构造数据集，会制造虚假的安全感，所得结论可能比没有评估更危险。

## 从 Workbench 到 CI/CD 的三步路线

### 第一步：Workbench 原型

先选择 10 至 20 条真实用例，由人工逐条打分，并快速迭代 Prompt。这个阶段的目标不是建立完整平台，而是形成对模型在当前场景中哪里可用、哪里不可用的基本判断。

### 第二步：半自动过渡

当人工评分成为瓶颈后，把有标准答案的用例切换为代码评分，主观和关键用例继续保留人工判断，并把数据集扩展到 100 对以上。

这一步采用混合评分：自动化处理可确定的部分，人继续负责机器难以可靠判断的部分。

### 第三步：CI/CD 管道

当评估进入生产管道后，把数据集扩展到 1000 对以上。每次修改 Prompt 都自动运行评估，以自动评分为主、人工抽检为辅；不及格的变更由质量门禁阻止上线。

评估体系本身也要持续迭代。第一版不会覆盖所有质量维度，实际使用会逐步暴露遗漏项和过于宽松的标准，再据此修订数据与评分规则。

## 总结

五句话说完：

1. Benchmark 测通用能力，业务评估测具体场景中的可用性，二者不能互相替代。
2. 最小评估集由输入样例、黄金答案、模型输出和评分四部分组成。
3. 人工、代码和 LLM 是三种互补的评分方式，应按任务的主观性与确定性组合使用。
4. 资料把 100 对真实、专业标注的数据作为能够指导决策的最低规模。
5. 评估应从 Workbench 人工原型开始，经半自动混合评分，最终进入带质量门禁的 CI/CD 管道。
