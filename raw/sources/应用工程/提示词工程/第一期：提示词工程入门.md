# 第一期：提示词工程入门

提示工程（Prompt Engineering）是系统化设计和优化输入指令，以引导大模型准确执行预期任务的方法体系。它并非试图改变模型本身的权重，而是通过结构化的任务约束和信息补充，发掘并稳定发挥模型已有的指令跟随能力。

## 从自然语言指令到模板工程

两年前，使用 AI 完成任务往往需要掌握编程、API 和特定机器学习模型。如今，诸如“把这段话翻译成英文”等自然语言指令即可驱动大模型执行任务。然而，同一大模型在不同提示方式下可能表现悬殊，差异往往来自指令的表达方式。

提示工程的核心在于“工程”二字——它不是临时拼凑一句 prompt，而是把任务说明、上下文、输入数据和输出约束分离，组织成可重复使用的模板。这种模板化的优势在于**解耦**，将稳定的任务逻辑与动态的输入内容分开。

例如，一个未经分离的提示词可能是：
*“请帮我总结一下这篇文章：[文章内容]，要求不超过100字，并提取3个关键词。”*

而经过模板分离（结合结构化标签的思想）的提示词则类似于：
```xml
<instruction>
请对以下提供的文章进行总结。要求：
1. 总结字数不超过 100 字。
2. 提取 3 个核心关键词。
</instruction>

<article>
{{此处替换为待处理的具体文章内容}}
</article>

<output_format>
总结：
关键词：1. 2. 3.
</output_format>
```
通过这种分离，团队可以针对不同文章复用同一个任务模板，确保模型输出的稳定性和一致性[6]。

## 提示词四要素

在 DAIR.AI 维护的提示工程指南（Prompt Engineering Guide）中，一个提示词被归纳为四个要素[2]：

1. **指令（Instruction）**：核心驱动要素，明确模型需要执行的具体任务。例如“将文本分类为中性、负面或正面”。
2. **上下文（Context）**：为任务补充外部信息、背景设定或演示示例（如少样本提示）。
3. **输入数据（Input Data）**：模型实际需要处理的具体数据或待回答的问题。
4. **输出指示（Output Indicator）**：约束模型输出的类型、格式或结构。例如要求输出 JSON 格式，或以特定前缀引导回答。

这四要素是一种实用拆分方法，而非每个提示词都必须齐备[1]。简单任务可能只需要“指令”和“输入数据”，而复杂任务才需要补充详尽的“上下文”与严格的“输出指示”。

## 零样本提示（Zero-Shot Prompting）

**零样本提示是指不向模型提供任何任务示例，仅依靠自然语言指令完成任务的方法**[1]。它是提示方法中最基础、成本最低的一种。

以下情感分类示例就是一个完整的零样本提示：
```
将文本分类为中性、负面或正面。
文本：我认为食物还可以。
情绪：
```
其中包含了指令、输入数据以及输出指示（用“情绪：”前缀约束模型在冒号后面填答案）。模型直接根据指令输出“中性”[1]。

如果在指令前加入了若干“文本 → 情绪”的案例作为上下文，就会变成少样本提示（Few-Shot Prompting）。当任务较复杂（如多步推理）或模型未能充分理解指令边界时，仅提供指令的零样本提示可能失效，此时通常需要转向少样本提示。

## 现代指令跟随能力的两类重要训练方法

为什么今天的模型能够仅凭一句零样本指令就理解并执行任务？
需要澄清的是，基础模型在预训练阶段（即在大规模语料上自回归预测下一个词）实际上已经涌现出了强大的零样本任务能力，基础模型也能在不更新梯度的情况下通过上下文学习完成任务[3]。但为了让模型更稳定、安全地听懂各种特定格式的自然语言指令，现代大模型通常依赖以下两类重要的训练方法[1][5]。

### 1. 指令微调（Instruction Tuning）

预训练的主要目标是“续写文本”。如果没有经过微调，输入“把这段话翻译成英文”，基础模型可能只会继续生成中文句子。

指令微调用于解决这一问题。其做法是使用大量以“指令 + 预期输出”形式组织的数据对模型进行再次微调（SFT），使其学会根据指令执行任务。Wei 等人在 2021 年发表（2022 ICLR 收录）的论文《Finetuned Language Models Are Zero-Shot Learners》中证明，指令微调能够显著提升语言模型在未见过的全新任务上的零样本学习能力[4]。简而言之，指令微调负责让模型听懂指令。

### 2. 人类反馈强化学习（RLHF）

仅理解指令仍然不够，模型可能偏离问题或生成不安全内容。RLHF（来自人类反馈的强化学习）用于使回答进一步符合人类的偏好和价值观。

根据 OpenAI 在 InstructGPT 等文献中的披露，对齐流程通常包含三步[5]：
1. **监督微调（SFT）**：收集高质量的人类演示数据对模型进行微调（此步有时与指令微调合并）。
2. **奖励模型训练（Reward Modeling）**：让模型对同一问题生成多个回答，人类标注员对回答质量进行排序，以此训练一个负责打分的奖励模型。
3. **强化学习优化（RL）**：使用强化学习算法（典型如 PPO 算法，但也存在其他替代算法）优化语言模型，使其倾向于生成高分回答。

指令微调和 RLHF 等对齐技术的结合，促成了 ChatGPT 等现代对话助手的诞生，使得模型从“续写机器”变为了能够响应自然语言指令的可靠引擎[5]。需要指出的是，RLHF 负责对齐人类偏好，它并不是大模型拥有零样本任务能力的必要条件[3]。
