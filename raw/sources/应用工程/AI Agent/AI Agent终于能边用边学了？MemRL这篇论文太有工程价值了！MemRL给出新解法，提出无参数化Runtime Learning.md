# 冻结权重的记忆效用学习：MemRL 无参数化 Runtime Learning

AI Agent 上线后，怎样在不修改模型参数的前提下持续学习，直接影响线上系统的长期效果。MemRL 由上海交通大学、MemTensor 等团队联合发布，试图让学习发生在外部记忆库中，使 Agent 能够从执行结果中积累经验。

## 记忆困境：语义相关不等于功能实用

现有的两种主流 Runtime Learning 路线各有缺陷：

1. **静态 RAG 检索**：系统保存历史成功操作，在面对新任务时进行语义检索。然而，语义最接近的记录在当前环境中可能毫无用处。例如，操作系统的 Agent 遇到任务时，可能检索到语义极其相似的历史操作记录，但历史记录依赖于当时环境下的特定用户账户，直接照搬不仅无用反而导致任务失败。
2. **模型参数微调（Fine-tuning）**：通过 RLHF、SFT、GRPO 等参数更新路线，将经验内化至模型权重中。这不仅需要较高算力，还极易用新知识冲刷掉旧知识，引发灾难性遗忘。

MemRL 针对静态 RAG 的问题，指出了**语义相关性不等于功能实用性**的根本差距，并放弃对权重的更新，将学习过程前置到记忆的检索和过滤阶段。

## 两阶段检索：从语义匹配到 Q-value 决策

MemRL 把记忆检索从被动的语义匹配改造成主动的 Q-value 决策问题。模型权重全程冻结，学习只发生在记忆库中，从而绕开持续微调带来的灾难性遗忘。

在 MemRL 中，Q-value 衡量一条记忆的历史效用：即过去将这条记忆用于类似任务时，Agent 的执行表现如何。系统据此区分真正有用的经验与语义相似但实际有害的经验。

检索分为两个阶段：
1. **语义粗筛**：使用 Embedding 余弦相似度筛选 Top-K 候选，保证记忆与当前任务在字面和语义上相关。
2. **效用精排**：使用从环境反馈中持续学习的 Q-value 对候选重新排序，让历史上有害的干扰记忆自动降权，高频有用的记忆升权。

## 反馈更新：效用更新、冷启动与淘汰机制

MemRL 包含三层核心组件：冻结语言模型、结构化记忆库（意图、经验、Q-value 三元组）以及检索-更新控制器。

推理开始后，选出的记忆被注入 Prompt，由冻结模型生成 Action 并在环境中执行。Runtime Learning 则发生在执行之后：系统使用环境反馈的奖励，通过蒙特卡洛规则调整本次使用记忆的 Q-value：

$$
Q(m) \leftarrow Q(m) + \alpha \cdot (r - Q(m))
$$

这一过程不计算梯度，亦不反向传播，实现完全的无参数化更新。

**记忆效用的工程示例**[^1]：
- **语义近但无用（降权）**：假设用户让 Agent “删除临时文件夹”。记忆库中有一条“在 Linux 中使用 `rm -rf /tmp/cache`”。但当前处于 Windows 环境。这条记忆被召回并执行报错，得到负向奖励。其 Q-value 随后被调低，未来再遇到类似 Windows 清理任务时，即便语义接近，也不会再被优先采纳。
- **语义稍远但有效（升权）**：一条关于“利用 PowerShell 脚本清理过期缓存并验证日志”的记忆，虽然在文本字面上偏离了简单的“删除文件夹”，但提供了完整的容错检查策略。在执行成功并获得正向奖励后，其 Q-value 提升。
- **冷启动与淘汰**：系统为新写入记忆库的三元组分配初始 Q-value。随着长期运行，不断失败或不再适用的记忆其 Q-value 会持续跌破设定阈值。这提供了一种工程上的**淘汰机制（Eviction）**，防止记忆库规模无限膨胀或被过时经验填满。

## 实验结果与边界

根据 MemRL 原论文的数据，系统的实验主要覆盖了 HLE、BigCodeBench、ALFWorld 和 Lifelong Agent Bench 四个基准[^2]。实验显示：
- MemRL 相对 MemP（作为基线）的累计成功率提高了 3.8 个百分点[^2]。
- 在 ALFWorld 与 OS 任务等场景中，这一提升最高达到 6.2 个百分点[^2]。

*(注：原分享中提及的 WebArena、SciWorld 等数据集名单存在出入，已根据原论文范围校正。原分享提到的“额外推理成本约为零”因缺乏论文明确的成本对照表支撑，按照非核心依据缺失原则已在重构中剔除。)*

MemRL 的主要价值在于让环境反馈改变未来的记忆选择。但在实际生产落地时，仍有两个需解决的直接工程边界：
1. **奖励信号的可靠性**：蒙特卡洛更新高度依赖环境能否给出准确的成功/失败奖励（$r$），而在许多开放式 Agent 任务中，定义并获取此奖励极其困难。
2. **多实例污染**：方案目前主要面向单个 Agent 的自进化。多个 Agent 实例共享记忆库时，单一实例的试错积累是否会污染全局库，尚未有完美解答。
