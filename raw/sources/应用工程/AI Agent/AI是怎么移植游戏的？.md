# AI是怎么移植游戏的？

2015 年，《血源诅咒》在 PS4 上发售。玩家等了 11 年，索尼仍未推出官方 PC 版。按照作者梳理的时间线，2026 年 9 月 22 日 Claude Opus 5.5 发布，10 月初，网友便把《血源》移植到了 PC。

同一个月出现的民间移植还包括 Switch 上的《织梦岛》《旷野之息》、PS2 上的《战神》，甚至 Switch 2 上发售仅一年的《咚奇刚》。其中不少项目已经能以 4K、60 帧运行，体验超过原机。作者注意到，这些 GitHub 项目的提交信息中，几乎处处都能看到 Claude 的名字。

在没有游戏源代码的情况下，移植者怎样让主机游戏在 PC 上运行？AI 又承担了哪些工作？理解这些项目，需要先区分游戏中的 CPU 指令、系统接口和 GPU 着色器。

## 一帧游戏画面怎样产生

游戏与电影都通过快速播放连续图片形成动态画面。电影的每一帧已经提前拍好，游戏却必须根据玩家的下一步动作实时计算：角色可能向左，也可能向右，画面无法预先确定。以每秒 30 帧为例，每帧只有约 33 毫秒。

CPU 先读取摇杆方向、攻击按键等输入，再计算游戏状态：主角移动多少、是否撞墙、敌人有没有发现主角、是否开始追逐。这些逻辑最终落实为一条条 CPU 指令。状态确定后，还需要据此绘制画面。

CPU 也能绘图，但现代游戏通常把这项工作交给 GPU。作者用一个简化估算说明其中的计算压力：1080p 画面每帧约有 207 万个像素，每秒 60 帧意味着每秒约需处理 1.2 亿个像素。若按 PS4 的 8 个 CPU 核心、每核每秒约 16 亿条指令估算，总计每秒约 128 亿条；即便 CPU 不做其他工作，每个像素也只能分到约 100 条指令，而真实游戏计算一个像素的颜色可能需要几百上千条指令。

许多像素采用相同算法，只是输入参数不同，所需运算也大多是加减乘除。GPU 因此可以用大量相对简单的计算核心并行处理这些工作。按作者列举的核心数量，Switch GPU 有 256 个核心，RTX 5090 有 21,760 个核心。

## Shader 与主机、PC 的编译差异

作者将显卡绘图方式的变化概括为：2001 年以前，显卡通常内置绘制算法，CPU 只需选择算法并传入参数；随着游戏效果越来越复杂，算法难以全部固化在芯片中，GPU 开始采用可编程设计，执行游戏开发者编写的小程序。

这些程序称为 Shader，即着色器。皮肤、金属、水面等材质分别需要不同的 Shader，大型游戏中往往有成千上万个。运行时，CPU 把相应程序交给 GPU，由 GPU 按程序计算画面。

不同显卡能够执行的 Shader 机器码并不相同。PC 游戏通常保存 DXIL、SPIR-V 等通用中间格式，在首次启动时编译成当前显卡能够执行的机器码。主机硬件固定，游戏可以预先保存对应 GPU 的版本。作者以此解释许多 PC 游戏启动时需要编译 Shader，而主机游戏通常不需要相同准备过程的差别。

把主机游戏移植到 PC，核心任务就是让原有 CPU 逻辑、系统调用和 GPU 程序能够在新平台上继续工作。不同主机的硬件架构不同，处理方式也随之变化。

## 《血源》：直接执行 CPU 指令，补齐系统与图形接口

### 同为 x64，仍然需要系统中间层

作者曾通关五次的《血源》具有一个有利条件：PS4 与本例中的 PC 都使用 x64 指令集，游戏的 CPU 指令可以直接在 PC 上执行。虽然两者的可执行文件格式不同，但编写一个能够在 PC 上加载 PS4 文件的程序，并不是项目中最大的工程。

真正需要适配的是系统接口。游戏申请内存、读写文件、读取手柄时，调用的是 PS4 系统提供的接口，Windows、Linux、macOS 不会直接提供这些接口。移植者因此用 AI 编写中间层：游戏需要哪个 PS4 接口，中间层就提供哪个，再调用 PC 操作系统完成实际工作。

这与模拟器有相似之处，但面向范围不同。通用模拟器希望支持各种 PS4 游戏，需要尽可能完整地实现接口；这个中间层只服务于《血源》，实现它实际使用的功能即可。作者称，这一中间层的代码量为 5,000 多行，属于相对较小的工程。

### 把 GCN 着色器翻译为 SPIR-V

CPU 指令能够直接执行，不代表 GPU 程序也能直接运行。《血源》的 Shader 已被编译成适用于 PS4 GPU 的二进制，与 PC 显卡所需的机器码不兼容。

PS4 采用 AMD 的 GCN 显卡架构，AMD 公开过对应指令集的格式。项目据此使用翻译器，把 GCN 指令转换成 SPIR-V，再通过 Vulkan 图形库将其转换成用户显卡对应的机器码。

这两步转换发生在运行时，便会带来额外开销。游戏进入新场景时，首次使用的 Shader 需要现场翻译，因而可能出现短暂停顿。

提前翻译能够减轻停顿，但前提是知道场景需要哪些 Shader。它们并不集中存放在某个固定区域，而是分散在程序各处，有些甚至动态生成，因此项目没有现成的完整清单。移植者只能收集玩家提交的 Shader 缓存，整理场景与 Shader 的对应关系，在游戏启动时预先翻译。没有玩家缓存的小众场景，仍然需要现场处理。

### 既有模拟器提供了图形基础

这项移植并非从零开始。shadPS4 模拟器此前已经开发多年，项目的渲染与 Shader 翻译部分由 shadPS4 分支而来。在此基础上，PS4 文件加载器、系统中间层、游戏与 shadPS4 的交互代码，以及其他代码的提交信息中，几乎都带有 Claude 的名字。

AI 承担了大量适配工作，既有开源项目则提供了重要的图形与翻译基础。

## 《织梦岛》：把 ARM 指令提前重编译为 PC 程序

### 从动态翻译转向提前翻译

Switch 的 CPU 使用 ARM 指令集，与本例 PC 的 x64 不同，因此《织梦岛》的 CPU 程序无法直接执行。

一种办法是在运行时动态翻译：遇到 ARM 指令，现场转换为 x64 指令后执行。作者将其概括为多数模拟器采用的方向，并用“一条原指令可能对应几百上千条 x64 指令”说明潜在开销。模拟器可以通过 JIT 等技术优化，但现场翻译仍然需要付出成本。

另一种办法是把翻译工作提前完成。《织梦岛》的移植采用了这条路线：先把整个游戏的 ARM 指令转换为 C 代码，再由 PC 编译器生成 x64 程序。

使用 C 作为中间步骤有两个好处。首先，把 ARM 指令转换为 C 代码已有大量成熟实现。作者举出的 REA 工程，就是用 AI 操作反汇编器 Ghidra 完成相关工作。过去这类工程的主要困难之一是工作量巨大，AI 改变了这一约束。其次，C 编译器在生成 x64 程序时还能继续优化代码。由于指令翻译已经在移植阶段完成，作者认为其 CPU 部分的运行效率可以接近原生 PC 程序。

### 指令与数据混在一起，不能简单逐字节转换

提前翻译仍有难点：程序中的指令与数据可能混合存放，同样的四个字节，既可能是一条指令，也可能只是一个数字。

为辨认代码，移植者从游戏入口开始，沿执行逻辑模拟程序，跟踪实际执行到的位置。模拟还必须足够准确，因为某些跳转的目标地址需要在程序运行时动态计算，单看静态机器码无法确定。项目因此专门开发模拟执行代码，用来侦测哪些内容属于指令。

在 PC 软件中，混排指令与数据也是常见的反逆向措施。设计得更复杂时，同一串字节还会根据程序状态分别充当指令或数据，进一步增加分析难度。作者认为，Switch 作为封闭系统，没有投入太多精力防止软件逆向，因此本例中的移植相对顺利。

### 系统服务与 Maxwell 着色器仍需适配

CPU 程序重编译后，还需要处理系统与 GPU 两部分。

游戏调用的是 Switch 系统服务，项目同样需要中间层，用 PC 操作系统实现对应接口。GPU 一侧也沿用“主机 Shader → SPIR-V → PC 显卡机器码”的路线，通过 Vulkan 接入实际显卡。

相比 PS4，Switch 的图形翻译还有额外困难：它采用英伟达 Maxwell 架构，而英伟达没有公开完整指令集。项目依赖开源社区多年积累的逆向资料，包括 envytools 整理的 GPU 文档和 Ryujinx 模拟器的 Shader 解码器，才顺利开发出翻译工具。

按照作者的介绍，重编译器、中间层和 Shader 翻译器几乎全部由 Claude 编写，人负责确定方向、审查代码，以及试玩和检验移植效果。

## 《旷野之息》：重编译完成，不等于全部场景测完

作者曾花一年通关《旷野之息》。这项移植复用了《织梦岛》的重编译器和中间层代码，许多技术难题已经由前一项目解决，新的突出问题是测试。

作者介绍的项目进度中，重编译一项达到 100%，表示整个游戏的代码已经被翻译出来。但《旷野之息》是一款开放世界游戏，地图广阔、迷宫众多，实际测过的场景约占 50%。作者观察到的运行效果已经流畅，但代码翻译进度与实际场景测试进度仍是两件不同的事。

## 有意思的事，也许会慢慢有意义

成熟模拟器已经很多，新的 3A 游戏也多到难以玩完，为什么还要花力气移植这些老游戏？

作者把这个问题放在“有意义”与“有意思”的区别中理解。人往往需要相信自己的工作有意义，才会觉得踏实；但有意思的事情，有时比当下被认定有意义的事情更有生命力。有意义却没有意思的事，可能逐渐失去意义；暂时看不出意义、却始终有意思的事，也可能随着时间获得新的意义。

在作者眼中，10 月的这些移植者像一群拿到屠龙刀的孩子，带着这个时代最聪明、最强大的工具，回到旧日的杂物堆中，修补十多年前留在亚楠街头的遗憾。

移植一个老游戏有意义吗？作者给出的回答是“没有”。但 4K、60 帧的画面亮起时，他仍会想起躲在被窝里集齐八件乐器、唤醒风之鱼的深夜，也会想起与大学室友在星辰钟楼击败玛利亚的周末。海拉鲁早就变了模样，可当他再次握起手柄，熟悉的音乐响起，他依然是那个热血沸腾的少年。
