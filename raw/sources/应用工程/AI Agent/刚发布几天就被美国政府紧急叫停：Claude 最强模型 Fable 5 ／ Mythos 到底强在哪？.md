> Claude 模型与 Agent 安全独立专题

官方标题使用了“被美国政府紧急叫停”的表述，但正文、视频简介和画面没有说明具体政府机构、叫停命令、发生日期或执行措施。因此，这项说法不能作为已核实事件；本文只整理正文实际展开的 Fable 5、Mythos 5、Agentic Execution 与分层安全机制。

## 同一底座的两种开放形态

资料称，Anthropic 于 2026 年 6 月 9 日同时发布 Claude Fable 5 与 Claude Mythos 5。两者不是完全不同的模型家族，而是同一底层能力的两种开放形态。

Fable 5 面向普通用户和开发者，在 Mythos 级底座前增加安全分类器和自动回退机制。Mythos 5 则面向经过审查的网络安全团队、关键基础设施机构和 Project Glasswing 合作伙伴，在部分高风险领域放宽或移除门控。两者的区别主要在访问对象、安全策略和能力释放边界，而不是简单的强弱关系。

资料把 Anthropic 的能力层级概括为 Haiku、Sonnet、Opus，以及位于 Opus 之上的 Mythos 级。Fable 5 是第一个面向普通用户大规模开放的 Mythos 级模型。

## 从模型能力转向 Agentic Execution

Mythos 5 与 Fable 5 的意义不只在回答质量，而在 Agentic Execution：模型可以在外部执行框架中长期使用工具、阅读代码、调试程序、寻找并修复漏洞，持续推进数小时乃至数天的任务。

需要区分模型与运行环境的职责。模型提供推理、代码理解、长上下文和工具选择能力；文件编辑、命令执行、测试、调试、浏览器、日志和权限控制由 Agent 运行环境完成。实际能力来自模型底座、工具环境、长上下文、推理预算和自动验证循环的组合，不是模型参数单独完成全部工作。

Anthropic 没有在资料所引材料中公开参数量、训练数据规模或模型架构。能够确认的是公开规格与行为：默认上下文窗口为 1,000,000 Token，单次请求最高输出 128,000 Token；每百万输入 Token 10 美元，每百万输出 Token 50 美元，资料称比 Mythos 预览版便宜一半以上。

两款模型只提供 Adaptive Thinking。开发者不能关闭推理时思考，也不能直接设置固定思考预算，只能通过思考力度参数控制深度。原始思维链不会返回给用户，产品可以不显示或只显示摘要。这一设计更适合长任务 Agent，而不是单轮问答接口。

## Project Glasswing 与漏洞发现

Mythos 预览版最先以高能力网络安全 Agent 进入公开讨论。Anthropic 没有直接开放它，而是启动 Project Glasswing，先交给防御团队寻找和修复关键软件漏洞。资料列出的合作方包括 Amazon、Apple、Cisco、Google、Microsoft、JPMorgan Chase 和 Linux Foundation 等机构。

资料转述 Anthropic 的结果称，Mythos 预览版在短时间内识别了数千个零日漏洞，包括 OpenBSD 中存在 27 年的问题，以及 FFmpeg 中存在 16 年、自动化模糊测试累计运行约 500 万次仍未发现的问题。这些数字来自厂商材料，不等同于独立复现结果。

Firefox 红队测试比较了相同崩溃样本下的漏洞利用能力：Opus 4.6 成功率不到 1%，Mythos Preview 为 72.4%。资料没有讲解任何可操作攻击步骤，重点在能力边界和安全影响。

## 从 N-day 缩短到 N-hour

N-day 漏洞已经公开并提供补丁，但大量设备尚未完成更新。过去，攻击者往往需要数天或数周把补丁反向工程成可用攻击；高能力 Agent 可能把这个窗口压缩到小时级。

资料转述 Anthropic 6 月 8 日的测试：Mythos Preview 针对 18 个近期 Firefox 安全补丁自动构建出 8 个可工作的远程代码执行利用程序，第一个耗时不到 1 小时。面对 21 个 Windows 内核漏洞，它在没有源代码、只有二进制文件的条件下生成 8 条从低完整性用户提升到 SYSTEM 权限的完整利用链，平均每条 API 成本约 2,000 美元。

这些结果意味着补丁发布与攻击可用之间的时间可能从 N-day 进一步缩短为 N-hour。月度补丁周期、季度维护窗口，以及难以快速升级的物联网、医疗和工业控制设备会面临更大压力。

## Fable 5 如何通过服务层公开能力

Fable 5 不是能力较弱的另一个模型，而是在同一底座外增加分类、拒绝、回退和访问控制。服务层分类器判断请求是否涉及网络安全、生物、化学、模型蒸馏等高风险领域；触发后，Fable 5 可以拒绝回答或自动回退到 Opus 4.8。

资料称安全机制被有意设置得较保守，可能误伤合法渗透测试、网络安全教学和正常生物医学研究；早期数据同时显示，超过 95% 的 Fable 5 请求不会触发回退。

门控效果在两组画面数据中十分明显：不带防护的 Mythos 5 在 Firefox 漏洞利用任务上成功率为 88.4%，开启拦截的 Fable 5 为 0%；自动化越狱测试中的攻击成功率，Opus 4.6、Opus 4.8 和 Fable 5 分别为 83.2%、56.0% 和 5.4%。官方还组织了超过 1,000 小时的外部漏洞悬赏，没有发现通用绕过方法。这些数字只能说明对应评测和门控配置下的结果，不能证明系统不会被其他方式绕过。

API 把拒绝表示为正常响应中的停止原因，而不是服务报错。开发者设置回退后，系统可以自动转交其他模型；输出前触发拒绝时不计费，触发回退时还提供缓存费用抵扣，减少长上下文重复计费。安全因此不是 Prompt 中的一条规则，而是分类器、拒绝、回退、计费、数据保留和访问控制共同组成的服务架构。

## 生命科学的收益与双重用途

Mythos 5 还进入 Anthropic 的内部蛋白设计流程。资料称，它能够自主选择结合位点、运行蛋白设计工具并从失败中恢复；14 个蛋白靶点中产生 9 个有潜力继续推进的候选，某些药物设计环节提速约 10 倍。

厂商材料还称，Mythos 5 能提出新的分子生物学假设，在盲评中约 80% 的情况下比 Opus 级模型更受科学家偏好，其中一个关于大肠杆菌蛋白的新机制假设后来获得独立实验室研究支持。另一个病毒外壳组装性质预测任务中，资料称 Mythos 级模型只靠生物学推理就超过了专门以蛋白质数据训练的专业模型。

这些能力可能加速药物发现、蛋白设计、基因组研究和生物信息分析，也可能降低危险生物设计、实验规划和知识整合的门槛。Fable 5 因而也对生物与化学请求实施回退；Anthropic 计划向部分生命科学研究者提供受限访问，在移除生物与化学门控的同时保留网络安全防护。

## 三类现实价值

Fable 5 的应用价值主要集中在三类高价值任务。

第一是长周期软件工程。资料转述 Stripe 的报告称，Fable 5 在一个约 5,000 万行的 Ruby 代码库中，用一天完成了一项原本需要一个团队工作两个多月的迁移任务。这是厂商与客户案例，不代表所有代码库都能获得相同收益。

第二是复杂知识工作。长文档、多图表、多表格和多步骤分析可以放入同一上下文，并通过多轮推理形成结构化结果，适用于金融分析、法律文件、战略研究和技术调研等场景。

第三是视觉与工具任务。资料列举了从科学图表提取精确数字、依据截图重建网页应用代码，以及在没有额外辅助工具的情况下仅凭画面完成《宝可梦 火红》任务。这些演示说明视觉信息正在被转化为可执行操作，但不能单独证明开放环境中的稳定性。

高规格也带来高成本。企业不应把所有请求都交给 Fable 5，而应使用模型路由：普通任务使用成本较低的模型，复杂、长周期和高价值任务再调用 Fable 5。

## 安全对象从模型扩展到整个系统

资料把大模型竞争概括为三个阶段：聊天能力、推理与代码能力，以及正在到来的 Agent 能力。第三阶段比较的不只是模型知道什么，而是谁能在真实环境中持续行动、使用工具、自我纠错并完成长任务。

传统内容过滤关注模型是否输出危险文字；Agent 安全还必须检查它在工具环境中会执行什么。错误修改代码、删除数据、绕过权限、运行危险实验、泄露机密或在边界不清时执行命令，都不是单靠拒答提示能够解决的问题。

企业需要同时控制工具权限、生产环境访问、沙箱、审计日志、人工审批、独立验证、回滚机制和 Prompt Injection 检测。高能力模型应被视为需要监管的数字执行者：可以写代码，但要经过代码审查；可以分析安全问题，但要留在隔离环境；可以处理重要数据，但必须记录权限、日志和输出产物。

资料称 Anthropic 将 Fable 5 与 Mythos 5 标记为受管控模型，要求 30 天数据保留，不适用零数据保留政策。官方说明这些数据不用于训练新的 Claude 模型，而用于安全监测、复杂攻击检测和减少误判。这是发布时的产品政策，实际使用前仍需核对当前条款。

## 结论

Mythos 5 代表高能力底座，Fable 5 是同一能力经过安全门控后的公开版本。它们的核心不只是对话质量，而是与工具、上下文、权限和验证循环结合后持续推进复杂任务。

正面影响包括软件工程、漏洞修复、药物设计和复杂知识工作的提速；风险则包括漏洞武器化窗口缩短、双重用途能力扩散和系统权限失控。能力越强，审计、沙箱、访问资格和领域门控越不能作为外围补丁，而必须成为产品架构的一部分。
